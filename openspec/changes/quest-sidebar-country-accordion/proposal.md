## Why

Строка страны в сайдбаре каталога `/quests` делает два разных действия. У 22 из 35 стран имя страны
на web уводит на отдельный экран `/quests/country/<alias>` (#1989), а счётчик с шевроном рядом
сворачивает список; у остальных 13 вся строка только сворачивает. По нажатию нельзя предсказать,
что произойдёт, а чтобы увидеть все квесты страны, приходится уходить из каталога на другой экран.
Владелец 21.09.2026: нажатие на страну открывает и закрывает её города, а открыть страну целиком —
не на новом экране, как принято в такой навигации.

Попутно видны два дефекта того же блока (замер прода 21.09.2026, 1280 px): свёрнутая страна занимает
86 px по вертикали против 54 px у строк фильтров над ней, поэтому список из 35 стран читается
разреженным; и состояние раскрытия не доходит до скринридера — у тумблера нет атрибута
`aria-expanded`.

## What Changes

- Вся строка страны становится одной зоной нажатия — тумблером раскрытия её городов с
  объявленным состоянием «развёрнуто/свёрнуто». Перехода на другой экран из сайдбара больше нет.
- **BREAKING** для решения #1989: ссылка сайдбара на лендинг страны удаляется. Разворот осознанный,
  по прямому запросу владельца. Сам лендинг `/quests/country/<alias>` и перелинковка на него в
  статическом HTML каталога и лендингов городов не меняются.
- Новый фильтр каталога «вся страна». Первым пунктом раскрытой страны, у которой два города и
  больше, идёт «Все квесты страны» со счётчиком. Выбор фильтрует сетку на месте квестами всех
  городов страны, заголовок — «Квесты: <страна>», сброс — существующим чипом «Все квесты».
  Выбор сохраняется между запусками и проверяется при восстановлении так же, как выбор города; в
  мобильном drawer он закрывает drawer, как выбор города.
- У страны с одним городом пункта «Все квесты страны» нет: её единственный город и есть вся страна.
- По умолчанию страны свёрнуты; раскрыта та, в которой лежит активный выбор, в том числе
  восстановленный из хранилища. Кнопка «Развернуть все / Свернуть все» остаётся.
- Свёрнутая страна, внутри которой выбран город или вся страна, показывает на своей строке маркер
  активного выбора — иначе после сворачивания не видно, откуда пришёл фильтр.
- Вертикальный ритм строк стран выравнивается по строкам фильтров; зона нажатия остаётся не меньше
  44 px.

Non-goals: страница-лендинг страны и её SSG; мультивыбор нескольких стран или городов; вынос
выбора в URL (выбор города в URL тоже не живёт — фильтр остаётся состоянием экрана); порядок стран
в списке.

Dependencies: нет — фильтр строится из уже загруженного каталога, бэкенд не нужен.
Fallback/mock policy: нет — новых источников данных и заглушек не появляется.

## Capabilities

### New Capabilities

- `quest-catalog-sidebar`: навигация сайдбара и drawer каталога квестов по странам и городам —
  раскрытие страны, выбор всей страны и города на месте, состояние раскрытия по умолчанию, маркер
  активного выбора, сохранение выбора и доступность.

### Modified Capabilities

Нет: в `openspec/specs/` спецификаций пока нет.

## Impact

- **Код:** `screens/tabs/QuestsSidebar.tsx`, `screens/tabs/QuestsScreen.tsx`,
  `screens/tabs/QuestsScreen.styles.ts`, `utils/questCatalogSelection.ts`,
  `screens/tabs/QuestsScreen.helpers.ts`; словари `quests` пяти локалей; `docs/features/quests.md`.
- **Платформы:** desktop web — сайдбар; mobile web, Android и iOS — тот же компонент в drawer.
  Сейчас поведение различается (на native у страны нет ссылки на лендинг); после изменения оно
  одинаково на всех четырёх поверхностях.
- **Локализация:** новые строки — пункт «Все квесты страны», его подпись для скринридера, описание
  каталога при фильтре по стране. RU/BE/UK/PL/EN через `@/i18n`; число квестов — существующей
  плюрализацией.
- **Видимое пользователю:** другой отклик на нажатие по стране, новый пункт внутри страны, страны
  свёрнуты при входе, плотнее список.
- **API/данные:** нет изменений.
- **SEO:** канонический `/quests` и его статический HTML не меняются; фильтр — клиентское состояние.
  Краулер получает ссылки на лендинги стран из статического HTML генератора
  (`scripts/generate-seo-pages.js:2837` — список стран каталога, `:3079` — «Все квесты страны» на
  лендинге города), а не из сайдбара, который заполняется только после загрузки каталога на клиенте.
- **Доступность:** тумблер страны объявляет состояние раскрытия; выбранный пункт объявляет выбор;
  зоны нажатия ≥44 px.
- **Производительность:** из пересчёта групп сайдбара уходит проход `buildQuestCountryLandingGroups`
  по всему каталогу; раскрытие страны не запрашивает данных.
- **Аналитика:** событий выбора фильтра в каталоге нет — не затрагивается.
- **Безопасность:** не затрагивается.
