## Context

See proposal.md. Два полных канонических артефакта #3449 остановлены до публикации. Идентичный нормализованный entry весит по-разному из-за двух номеров карт загрузки; перенос импорта не решает механизм. Реальный исходный пробный декодер включён в сжатие, baseline воспроизведён побайтно.

## Goals / Non-Goals

Уменьшить доставляемые служебные байты при прежней семантике Expo и прежнем пределе. Не менять карты/индексы ради удачного сжатия, сжатие, pins, гранулярное разбиение или пользовательские экраны.

## Decisions

Эмитировать один целочисленный mapId в массиве, версию продолжает проверять общий mc1 registry. Runtime один раз определяет индекс из singleton либо корректной legacy-пары, затем исполняет прежнюю проверку таблицы/индекса и тот же cache/ordered expansion. Caller-local maps не объединяются по одному moduleId. Строки/объекты/scalar worker inputs не переписываются.

Legacy-пары остаются допустимы для старых артефактов и инструментов. Новые массивы доставляются только в связанной content-hashed паре runtime/registry/chunks штатного выката. Ни новый запрос, ни новый async-root не добавляется.

Отвергнуты: новый root и импорт существующего экрана (оба канонических замера остались красными); статический полный planner runtime увеличивает eager-граф статьи при 778 Б запаса и 18/18 запросах; перестановка mapId не устраняет повтор версии и не даёт достаточного сокращения.

## Risks / Trade-offs

- Старый decoder не понимает singleton → сохраняется атомарная штатная публикация связанных content-hashed файлов и старых overlay assets.
- Исходная проба ровно на пределе → фактический итог принимает только неизменённый canonical guard; не обещать pass до свежего артефакта.
- Ошибка совместимости может затронуть общий web-loader → реальные producer/resolver fixtures, ошибочные схемы, старые артефакты и все 252 замыкания проверяются до review; runtime-проверка после публикации.

## Migration Plan

План → строгая проверка → минимальные source/test правки → независимый review/gate → явные пути main/push → общий выкат с #3449 → live SHA/boot/article/planner/cleanup. Ошибка бюджета до publish сохраняет прод. Откат после реального дефекта — штатный revert и согласованный frontend pipeline, без ручного изменения backend.
