## Why

The first «Наш день» export uses three JPEGs and three captions across 15 seconds, with no audio stream. The production prompt mandates that fallback, so successful execution can still omit character movement, dialogue and the actions that connect a decision to the trip.

## What Changes

- Define the deliverables and acceptance checks for an acted animated Reel. Require reciprocal dialogue and motion inside the shot.
- Record the rendering and voice prerequisites before generating a batch. Preserve a storyboard or animatic as a draft if production is blocked.
- Apply the new format to the season premises and a shot-by-shot Leskowiec example. Route Codex, Claude and Grok to the same instructions.

## Capabilities

### New Capabilities

- `animated-reel-production` — shot planning, rendering and acceptance for animated MeTravel episodes.

### Modified Capabilities

None.

## Impact

- User-visible result: a short narrative with visible actions, audible interaction and a consequence on the route or site.
- Platform impact: none. Localization impact: none. The pilot uses Russian editorial dialogue and timed subtitles.
- Existing article/API provenance, rights and publication authority still apply. No application API/data, SEO, runtime accessibility, performance or analytics impact because the edits are production instructions and examples. Media security depends on authorized reference handling and voice permissions.
- Dependencies: a renderer capable of character motion, cleared visual references, and a permitted voice source. In their absence, deliver an explicitly labeled draft with the exact blocker.
- Out of scope: a render or upload for this review, new provider subscriptions, changes to the existing live-footage montage tool, or publication. No unresolved decision blocks the prompt revision.
