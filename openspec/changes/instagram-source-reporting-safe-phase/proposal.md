## Why

В #2680 требуется различать Instagram и видеть сессии, регистрации, начало создания поездки и публикации по источнику. Сейчас CLI показывает только каналы и общий список событий, месячная сводка не связывает их с источниками.

20.10.2026 владелец выбрал сохранить замер #2659: классификатор меняется только после его завершения. Независимая отчётная часть выделена в #2694.

## What Changes

- Добавить к `--channel-breakdown` отдельный отчёт GA4 по sessionSource/sessionMedium и трём событиям вклада автора.
- Включить такой разрез по месяцам в существующую месячную сводку, сохранив итоги, каналы, критерии качества и ограничения данных.
- Записать готовые UTM-ссылки profile/story/reel и правило подстановки целевого пути; обозначить их активацию только после #2659 и выката классификатора #2680.

## Capabilities

### New Capabilities

- `ga4-source-conversions`: отдельные сессии и счётчики событий по источникам, включая Instagram, с явным отсутствием/недоступностью данных.

### Modified Capabilities

Нет: месячная сводка получает дополнительный разрез без изменения существующих требований к её итогам.

## Impact

- Platform impact: none — локальные CLI и документация; desktop web/mobile web/Android/iOS код не меняется.
- Localization impact: none — UI отсутствует, отчёт владельцу по-русски.
- Data/API: read-only GA4 Data API runReport; sessions запрашиваются отдельно от eventName/eventCount. Дополнительные поля JSON и таблица Markdown.
- Analytics: только чтение; KPI Unassigned, acquisition-транспорт, consent, native-аналитика и Метрика не меняются.
- Performance/security: два дополнительных разреза; существующие дедлайны, пагинация и маскирование ошибок/секретов сохраняются.
- SEO/accessibility: none, страницы и UI не затронуты.
- Dependencies: текущий read-only доступ к GA4; жёсткой зависимости от #2659 для этой фазы нет. #2680 остаётся заблокирована #2659.
- Fallback/mock policy: unit-фикстуры допустимы; приёмка — реальные CLI-запросы. Отсутствующие наблюдения не превращаются в выдуманные нули.
- Preserve: прежние итоги, channelBreakdown Unassigned, независимый знаменатель, календарные окна, ограничения качества и частичный успех источников.
- Non-goals: изменение классификатора/UTM-продюсеров, реального профиля или постов Instagram, серверов и backend.
- Open questions: нет; запрет на клиентские изменения подтверждён владельцем.
