## Why

Полные книги Беларуси и Польши собраны только в акварели (#2786, поезда A–D).
Модель публикации различает страны и физические размеры, но не несколько
визуальных редакций одной страны. Владелец 30.10.2026 поручил после акварели
сделать остальные стили; карточка #2854 (FE-BOOKS-E1) — фотографический стиль
из настоящих снимков автора 1. Копирование генератора под каждый стиль создаст
несовместимые ревизии, поэтому нужна одна общая идентичность
country + visualStyle + revision.

## What Changes

- Общая идентичность издания `country + visualStyle + revision`.
  `BookVisualStyle = watercolor | photo | graphic | fantasy`; уникальность
  публикации — по паре страна+стиль, а не по стране. Существующая акварель
  получает `visualStyle: watercolor` неявно и сохраняет id, slug, URL и
  неизменяемые файлы.
- Фотографическая редакция обеих стран в двух размерах: отдельные `bookId`/
  `slug`, тот же состав BY31/PL30, те же три страницы на место, те же QR,
  финальная карта и текст обложки. Изображение места — цельный коллаж из
  оригиналов автора 1 той же выбранной статьи с мягким переходом в бумагу;
  никаких стоков, AI-реализма или увеличения пикселей.
- `PhotoEvidence` для каждого использованного снимка: pointId, articleId,
  authorId 1, originalUri, sha256, размеры, права, дата проверки и наблюдаемое
  содержание кадра. Коллаж хранит рецепт и реальные ppi каждого снимка.
- Параметризация общего рендера без копий: шрифты заголовка/текста, подписи
  (alt, титул, страница использования, выходные данные) и обложка зависят
  от стиля. Эпиграф обложки — существующий движок персонализации с
  утверждённым Marck Script.
- Выбор стиля на странице издания и в каталоге; старые URL акварели
  сохраняются.

Не входит: изменение состава мест или живых статей, другие стили
(graphic/fantasy — #2855/#2856), облачный рендер, платный заказ, backend,
store release, подмена низкого разрешения увеличением.

## Capabilities

### New Capabilities

- `book-visual-styles`: несколько визуальных редакций одной страны с общей
  идентичностью, доказанным происхождением фотографий и честными
  ограничениями разрешения.

### Modified Capabilities

- `ready-travel-books`: каталог и страница издания различают стиль; акварель
  остаётся доступной по прежним адресам.

## Impact

Platform impact: desktop web | mobile web — выбор визуальной редакции,
карточка, предпросмотр и скачивание. Генератор — локальный общий слой;
отдельные Android/iOS файлы и store release не меняются; открытие `/books`
из native сохраняет существующий web-only маршрут.

Localization impact: редакционные книги RU; app-owned названия стилей,
состояния и ошибки RU/BE/UK/PL/EN через namespace `books`. Исходные подписи
API не переводятся на клиенте.

Data/API: `PublishedBook.visualStyle`, уникальность `country+visualStyle`,
`PhotoEvidence` в данных подготовки, новые неизменяемые пути
`/travel-books/<bookId>/<revision>/`. Backend и API не меняются.

SEO: новые канонические `/books/<slug>` страницы редакций с собственным
заголовком; старые адреса не меняются. Accessibility: alt изображений и
подписи стиля читаются; выбор стиля — обычные элементы управления.
Performance: в бандл попадают только метаданные; PDF и preview — внешние
файлы той же ревизии. Security: только same-origin неизменяемые ресурсы с
SHA-256. Analytics: существующие события книг получают стиль через bookId.

Dependencies: #2807 (закрыт 01.11.2026); связаны #2799–2802, #2786; модель
публикации — после коммита F1 #2808 в `catalog`/`publication`.

Fallback/mock policy: заглушки только в unit-тестах. Production не получает
недостающие фотографии, неподтверждённые квесты, фальшивые 300 ppi или файлы
другого стиля; planned/partial не выдаются за ready.
