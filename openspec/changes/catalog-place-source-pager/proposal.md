## Why

В каталоге `/places` карточка уже связанного сервером места открывает только первичную статью, даже когда карта умеет показывать несколько материалов того же объекта. Задача #3076 открывает остальные статьи из той же карточки.

## What Changes

- Карточка с несколькими материалами показывает заголовок и счётчик, по стрелкам меняются фото, заголовок и ссылка на статью.
- Первое перелистывание загружает список материалов. На время загрузки и при сбое доступна первичная статья.
- Название и координаты места, навигация, сохранение и оценка сохраняют прежнее назначение. Одиночные записи выглядят по-прежнему.

## Impact

- Platform impact: shared, desktop web, mobile web, Android и iOS. Движки карты и платформенные файлы сохраняют существующие границы.
- Localization impact: all current locales (RU/BE/UK/PL/EN). Используются существующие подписи.
- Data/API: каталог сохраняет серверные `place_id`, `source_count` и `primary_source`. Источники берутся из существующего endpoint карты. #3075 нужен для проверки объединения исторических записей и их общего рейтинга.
- Fallback/mock policy: одиночная запись или доступный первичный материал остаются рабочими при старом, пустом, частичном или ошибочном ответе. Фикстуры предназначены для автоматических тестов, приёмка использует живой API.
- Accessibility и performance: клавиатура, live region и зоны касания общего pager, запросы по действию, одно активное фото. Маршрут, SEO, аналитика и политика переходов сохраняют действующие контракты.
- Out of scope: изменение данных и рейтинга, эвристики совпадений, редактура статей, изменение картографического движка.
- Open questions: открытых вопросов для реализации нет. Проверка исторических записей начинается после #3075.
