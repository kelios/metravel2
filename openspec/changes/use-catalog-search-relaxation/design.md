## Context

`ListTravelBase` открывает цепочку из нескольких подписок React Query. `GET /api/travels/` в режиме `relaxation=auto` возвращает `stage`, `strict_count` и `removed_filter_keys` вместе с обычной страницей результатов.

## Goals / Non-Goals

Один первоначальный запрос каталога на набор условий и стабильный этап при прокрутке. Справочники, фасеты и рекомендательные запросы имеют отдельные контракты.

## Decisions

- Opt-in включается на уровне публичного экрана. Адаптер проверяет область выдачи и добавляет параметры транспорта отдельно от исходных фильтров.
- React Query получает этап вместе со следующей страницей. Новый ключ запроса начинает с первой страницы без закреплённого этапа и отменяет предыдущий запрос по сигналу.
- Предзагрузка гостевой страницы `/search` использует тот же URL. При ответе старого сервера первая страница отображает точную выдачу в исходных условиях.
- Локализованная подсказка строится по этапу и ключам из ответа. Число точных совпадений хранится отдельно от числа показанных маршрутов.

## Risks / Trade-offs

- Несовпадение URL предзагрузки добавит запрос. Паритет проверяется тестом транспорта.
- Отсутствующий или изменённый этап в ответе страницы 2 приводит к ошибке догрузки, чтобы не смешивать выдачи.
- В режиме #3018 сервер возвращает публичную область видимости. Сессия транспорта и клиентский фильтр заблокированных авторов остаются на штатном пути.
