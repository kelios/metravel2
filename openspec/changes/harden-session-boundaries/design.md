## Context

На web сессия хранится в HttpOnly cookie. Нативные запросы берут пару токенов из SecureStore. Ссылка активации содержит одноразовый секрет, который удаляется из видимого URL.

## Decisions

- Отзыв на Android и iOS сохраняется отдельным маркером без секрета. Текущий процесс также отклоняет чтение, пересёкшее отзыв. Новая запись снимает маркер только после сохранения токена.
- На web запрос выхода подтверждает серверную очистку. При отказе сохраняется видимый статус аккаунта и появляется сообщение об ошибке. После подтверждённого удаления аккаунта применяется локальная очистка.
- Согласие на вход относится к конкретному секрету активации. До нажатия серверный запрос отсутствует.

## Risks / Trade-offs

Если оба нативных хранилища недоступны, запрет в памяти действует до перезапуска. Прямой запрос к серверному endpoint требует собственной защиты.
