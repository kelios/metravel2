## Why
Фото точки после таймаута показывает только краткий тост (#2276). Владелец в #3313 18.11.2026 выбрал сохраняемую ошибку; реализация #3452.

## What Changes
Показывать сообщение в редакторе до закрытия или нового выбора фото. Отмена picker сохраняет ошибку. Новая точка не наследует старую ошибку. Тост остаётся немедленным каналом.

## Capabilities
### New Capabilities
- `point-photo-feedback`: постоянная ошибка таймаута фото точки.

## Impact
Platform impact: Android, iOS. Web без изменения поведения.
Localization impact: all current locales — RU/BE/UK/PL/EN, сообщение и доступное закрытие.
Data/API, SEO, security, analytics: без изменений; меняется только UI-отклик. Accessibility: читаемое сообщение и кнопка закрытия. Performance: без новых запросов и таймеров.
Dependencies: решение #3313 получено, multipart upload API сохраняется.
Fallback/mock policy: unit подменяет транспорт/picker, не состояние реального компонента; runtime проверяется отдельно.
Existing behavior to preserve: блокировка сохранения #3213, тосты ошибок/разрешений #2276, web, обложка и галерея.
Non-goals: автоповторы, изменение API/таймаутов/разрешений, публикация сборки в магазинах.
Open questions: нет.
