## Purpose

Позволяет читателю менять порядок выдачи каталога мест, сохраняя текущий поисковый контекст.

## ADDED Requirements

### Requirement: Choose a catalog sort mode

Каталог SHALL предлагать обычный порядок, средний рейтинг, название, число оценок и число статей. Выбранный режим SHALL быть виден и доступен с клавиатуры и касанием.

#### Scenario: Select an option with the keyboard

- **WHEN** читатель открывает меню с клавиатуры и выбирает другой порядок
- **THEN** видимая и доступная подписи показывают текущий вариант, а фокус возвращается к кнопке меню

### Requirement: Apply the same sort across all pages

Каталог SHALL использовать серверный `sort` для каждой страницы и сохранять фильтры и поиск при смене режима. `default` SHALL отправляться без параметра `sort`.

#### Scenario: Change or revisit a sort after loading multiple pages

- **GIVEN** страна, категории и поиск активны и в текущем режиме загружена вторая страница
- **WHEN** пользователь выбирает новый или ранее использованный режим
- **THEN** первый запрос выбранного порядка использует `page=1` с теми же фильтрами, а дозагрузка использует тот же порядок

#### Scenario: A sorted response fails

- **WHEN** первая страница выбранного режима завершается ошибкой
- **THEN** каталог показывает существующее состояние ошибки и может повторить запрос выбранного режима
