## Why

Поиск по названию на /places наследует стартовые категории. Пользователь может получить пустую выдачу для существующего места, даже когда сам ничего не фильтровал (#3082).

## What Changes

- Искать по всем категориям выбранной страны, если есть текст и человек не выбирал категории.
- Показывать область выдачи на узком и широком экране. В пустой явной подборке дать действие, которое снимает категории с сохранением остальных параметров.

## Capabilities

### New Capabilities

- `catalog-place-search-scope` — область каталога при просмотре, поиске и очистке запроса.

## Impact

- Платформы — shared, desktop web, mobile web, Android и iOS. Локализация — all current locales (RU/BE/UK/PL/EN).
- API сохраняет GET, параметры и форму ответа. Используем существующие режимы запроса с категориями и без них. Серверная работа и моки в продукте не нужны. Ошибку можно повторить с тем же контекстом.
- Сохраняем стартовую подборку, debounce, пагинацию, сортировку, навигацию и SSR. Контроль бюджета — число и параметры запросов списка, фасетов и агрегата.
- Действия доступны с клавиатуры и имеют локализованные имена. SEO-метаданные, авторизация и аналитика не затронуты.
- Состав подборок, поиск по радиусу на карте и изменения backend вне scope. Открытых вопросов к контракту нет.
