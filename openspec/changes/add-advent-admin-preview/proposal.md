## Why

Superusers need to inspect and exercise the full Advent campaign before the public calendar opens.

## What Changes

- Add an opt-in preview on the existing Advent page for authenticated superusers.
- Let preview users open every campaign door and try interactive tasks without updating Advent progress, rewards or campaign analytics.

## Capabilities

### New Capabilities

- `advent-calendar`: role-gated campaign preview.

### Modified Capabilities

None.

## Impact

Shared Advent UI and five locale resources. Existing campaign and progress API contracts stay the same.
