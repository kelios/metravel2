## Why

Пользователю нужна готовая книга, которая подсказывает красивые места для поездок и после путешествия становится личным фотоальбомом-дневником. Существующий экспорт личных статей этого сценария не покрывает; владелец 26.10.2026 заказал план нового релиза с двумя книгами по Беларуси и Польше.

## What Changes

- Новый бесплатный публичный раздел «Книги путешественника»: `/books`, карточки изданий `/books/[slug]`, предпросмотр, выбор физического формата, скачивание без регистрации.
- Два законченных русскоязычных издания: «Беларусь. Замки, города и природа» и «Польша. Замки, города и горы». Не менее 30 конкретных мест в каждой, из опубликованных путешествий автора user_id=1; число внутренних страниц выводится из состава, обложка отдельная. Беларусь содержит 31 выбранный владельцем объект, Польша — 30 проверенных авторских точек.
- Два самостоятельных макета: компактный 150×100 мм и A5 148×210 мм для фотографии 100×150 мм. Одно содержание, разные физические ограничения, без масштабирования A4.
- На место отводятся три страницы: цельный акварельный коллаж с описанием и двумя QR («Место на карте», «Статья на сайте»), свободная страница для личного фото и чистая дневниковая страница. Третий QR «Квест» добавляется только для опубликованного маршрута, включающего этот объект. Нет фоторамок, служебной шапки и подписи об AI-иллюстрации на каждой странице; происхождение сохраняется в записях подготовки.
- Карта всех выбранных мест последней содержательной страницей с читаемыми номерами и легендой из существующих завершающих чек-листов.
- Необязательный текст обложки: два согласованных изречения или собственный ввод. Персональный PDF обложки создаётся локально из проверенного чистого шаблона и полного шрифта; базовая книга и её публичная ревизия остаются неизменными.
- Готовые файлы для дома, последовательные страницы для типографии, инструкции печати/сборки и два листа наклеек на страну.
- Выбор типографии: 6 областных центров Беларуси и 18 административных центров 16 воеводств Польши; местная точка либо честно обозначенная доставка. Запрос через внешний сайт и скачиваемый пакет; прямая передача заказа — отдельный этап после проверки партнёра.
- Нормативный дизайн и план реализации: `docs/features/travel-memory-books.md`, `docs/design/travel-memory-books-v1.md`. Статусы задач остаются на MCP-борде.

Non-goals первого релиза: редактор содержания пользовательской книги/фотографий (кроме текста отдельной обложки), оплата, платный доступ, реальные заказы в типографию, автоматический перевод книг, выпуск отдельных тематических и квестовых серий, native build/store release. Тематические серии и партнёрская интеграция получают отдельные backlog-карточки.

## Capabilities

### New Capabilities

- `ready-travel-books`: каталог и версионированное содержание двух готовых изданий, предпросмотр, скачивание, навигация и измерение воронки.
- `travel-book-print-packages`: физическая геометрия книги, домашние/типографские файлы, дневник, наклейки, инструкции и проверенные сведения о печати.

### Modified Capabilities

Нет. Существующие A4-книги, экспорт личных поездок и печатные сценарии квестов сохраняют свой контракт.

## Impact

Platform impact: desktop web | mobile web. Общие данные/чистая геометрия проверяются один раз; responsive UI — mobile first и desktop. Android/iOS не получают новый встроенный сценарий в этом релизе; открытие обычного публичного URL не является новым native API.

Localization impact: RU/BE/UK/PL/EN для app-owned UI, namespace `books`; редакционный контент/PDF только `ru`, с явной подписью языка. Будущие BE/PL издания — самостоятельные редакционные версии.

Data/API: версионированный статический manifest `ReadyBook`, фиксированный снимок мест и артефакты с SHA-256. Новый backend API для v1 не нужен. Предлагаемые пути: `data/travelBooks/`, `types/readyBook.ts`, `services/book/readyBooks/`, `components/books/`, `app/(tabs)/books/`. Сборка локальная, платные облачные задания не используются.

Dependencies: работающие общие PDF/печать/навигация; точное происхождение каждой фотографии из выбранной статьи автора 1 и права; проверка текста, координат и связи квестов; подтверждение печатного профиля конкретным провайдером. Смежные #2354, #2369, #975 — reuse, не жёсткие блокеры; #1473, #2352, #2358 — другие продукты.

Fallback/mock policy: прототипы допустимы до приёмки; опубликованный manifest не содержит фиктивных точек/провайдеров или неготовых файлов. Ошибка скачивания имеет повтор; недоступный провайдер не получает обещания заказа.

SEO: canonical/локализованные страницы каталога через действующие helpers, без ручной правки robots/sitemap. Accessibility: клавиатура, текстовый список страниц и мест, масштабирование, доступные подписи. Performance: ленивый предпросмотр, скачивание уже собранных файлов, без рендера всей книги при открытии каталога. Security: экранирование редакционных данных, встроенные ресурсы PDF, внешние переходы через `utils/externalLinks.ts`, без передачи персональных данных типографиям. Analytics: просмотры издания, предпросмотр, выбор профиля, скачивания, инструкция и переход к провайдеру; клик не считается напечатанным заказом.

Прямое поручение владельца 30.10.2026 разрешает реализацию уточнённого состава и согласованного образца v4. Частичный цифровой выпуск чтения/пробной печати явно отделяется от полной производственной готовности. Планирование не означает реализацию или публикацию продукта. Даты поставки определяются после проверки ёмкости; sprint создаётся `active`, закрывается по готовности двух комплектов и производственной приёмке.
