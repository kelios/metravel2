## Context

Меню в `PlacesScreen.tsx` читает локальный режим из контроллера. `usePlacesCatalogQueries.ts` разделяет кэш по режиму, поиску и фильтрам, но сохраняет несколько ранее загруженных страниц каждого режима. Подписи текущего меню вычисляются один раз.

## Decisions

- Расширить `PlacesCatalogSort` в `api/places.ts`. Существующий код собирает URL для всех явных режимов и оставляет обычный порядок без `sort`.
- При выборе другого режима сбросить только точный ключ списка выбранного режима и текущего поискового контекста. Это гарантирует страницу 1 для холодного и тёплого кэша. Повторный выбор уже активного режима закрывает меню без запроса. Смена фильтров внутри одного режима сохраняет текущий механизм временной выдачи.
- Использовать текущее меню и стили. Локализованные подписи вычислять при смене языка и сообщать выбранный порядок в доступном имени. На web общий Menu использует существующий focus trap по запросу потребителя, с переходом стрелками и закрытием Escape.
- Сохранить кэш фасетов и подборок, политику повторов, ссылку каталога и контракт аналитики. Порядок API сохраняется без клиентской пересортировки.

## Risks / Trade-offs

- Тёплый кэш может показать старые страницы или вызвать повтор каждой страницы. Сброс точного ключа исключает оба сценария. Ключи остальных режимов и ресурсов остаются доступны.
- Пять вариантов должны помещаться в существующий прокручиваемый web-поповер. У нижнего края меню привязывается к верхней стороне кнопки, если там больше места. Проверить узкий и широкий экран, клавиатуру и возврат фокуса.

## Migration Plan

Изменение добавляет параметры к текущему GET. #3079 выкатывает порядок до итоговой проверки. Откат фронтенд-коммита убирает три пункта меню без миграции.

## Validation

Jest API, контроллера и меню, typecheck, lint, `npm run test:i18n`. После независимого ревью проверить опубликованный API и браузер mobile web, затем desktop web. Native использует прежнее меню с новыми подписями и общим контроллером.
