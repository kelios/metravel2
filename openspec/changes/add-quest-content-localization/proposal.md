## Why

Интерфейс metravel.by переведён на пять языков (RU/BE/UK/PL/EN), а сами квесты — только на русском:
220 квестов в 167 городах 35 стран, 2 186 шагов, 2,72 млн знаков (замер прод-API 04.10.2026).
Пользователь с польским или английским интерфейсом получает русские легенду, задание и подсказку и
должен вводить ответ по-русски — в 1 156 шагах список принимаемых ответов кириллический. Бэкенд язык
запроса не читает вовсе: `GET /api/quests/` с `Accept-Language: en|pl` возвращает тот же русский текст.

`docs/RULES.md` запрещает переводить API-контент на клиенте «without a separate content-locale/API
contract». Этот change и есть такой контракт — для квестов, с расширением на новые языки без
миграций и без правок клиентского кода.

## What Changes

- Вводится понятие **локали контента квеста**: русский текст остаётся источником, перевод хранится
  отдельной записью на пару «квест + локаль» и публикуется целиком.
- Read-API квестов принимает `?lang=<код>` и сообщает в ответе, на каком языке контент реально
  отдан (`content_locale`) и на каких он доступен (`available_locales`). Нет опубликованного
  перевода — квест отдаётся целиком по-русски; смесь языков внутри одного квеста исключена.
- Клиент запрашивает квесты на языке интерфейса; ключи кэша запросов и офлайн-копии различают
  локаль; при fallback показывается честная пометка «квест доступен на русском».
- Проверка ответа учитывает локаль контента: принимаются варианты на языке перевода и исходные
  русские; нормализация ввода выбирается по локали через реестр с универсальным fallback.
- Прохождение, счётчики, рейтинг, первопроходец, значки и адреса страниц от языка не зависят.
- Появляется конвейер перевода: выгрузка русского источника → перевод с глоссарием → структурная
  и смысловая проверка → запись в API; правка русского текста помечает перевод устаревшим.
- Набор локалей контента не объявляется вторым списком: фронт берёт его из `i18n/config.ts`,
  бэкенд — из одной настройки; новая локаль = строка в настройке + запуск конвейера.

Не входит: языковые префиксы URL, `hreflang`, локализованные SSG-страницы и sitemap — это
отдельный SEO routing contract (`docs/RULES.md`), оформляется своим change после появления
переводов. Перевод отзывов, статей-путешествий, мест и прочего пользовательского контента не входит.
Финальные видео с вшитой русской надписью в этом change не перерисовываются.

Platform impact: shared (desktop web, mobile web, Android, iOS) — общий data-слой и общий визард;
отдельного device gate нет: platform-specific поведение не меняется. Localization impact: все текущие локали
RU/BE/UK/PL/EN; новые app-owned ключи для пометки fallback — во всех пяти.

## Capabilities

### New Capabilities

- `quest-content-localization`: на каком языке отдаётся и показывается контент квеста, как
  выбирается fallback, как проверяется ответ в переведённом квесте и что остаётся общим для всех
  языков.

### Modified Capabilities

Нет: `quest-progress-reconciliation` и `quest-catalog-sidebar` своих требований не меняют —
прохождение по-прежнему привязано к `step_id`, состав каталога от языка не зависит.

## Impact

- **Backend (`area=back`, read-only зависимость из этого workspace):** таблицы переводов, `?lang=`
  на read-эндпоинтах квестов, admin-эндпоинты записи и статуса переводов, локаль в карточке
  результата и в статистике ответов. Старые клиенты без `lang` получают прежний русский ответ.
- **Frontend data-слой:** `api/quests.ts`, `api/queryKeys.ts`, `api/questBundleCache.ts`,
  `utils/questAdapters.ts`, `utils/questAnswerEvaluation.ts`, `utils/questAnswerMorphology.ts`,
  `utils/questCityAlias.js`.
- **Frontend UI:** деталь и каталог квестов (пометка fallback), печать, шаринг, напоминания —
  получают локализованный текст из бандла без собственной логики перевода.
- **Контент-инструменты:** новый конвейер перевода в `scripts/`, локализация линтеров контента,
  обновление skill `metravel-quest` и `docs/features/quests.md`.
- **SEO:** без изменений — статический HTML и canonical остаются русскими до отдельного change.
- **Аналитика:** `QuestAnswerAttempt.locale` должна нести локаль контента; воронка по `step_id`
  не меняется.
- **Производительность:** размер ответа API не растёт (отдаётся один язык); в кэше запросов
  появляется измерение локали.
- **Безопасность/приватность:** новых персональных данных нет; запись переводов — только admin.
