## Decisions

1. Использовать публичный адаптер Expo Router со штатными TabRouter и BottomTabView. В web-приложении собственный док, поэтому для его отрисовки не нужны заменители непосещённых экранов. Регистрация имён, фокус, хранение посещённых экранов, предзагрузка и fullHistory остаются у Expo.
2. Нормализовать активную секцию до ключа действительно подсвеченного чипа до передачи в web-границу. Для пустой секции и gallery пользователь видит один и тот же чип.
3. Выделить подпись слайда в собственную завершённую SSR-границу. Подпись зависит от текста, номера и числа фотографий.

На web код мобильного списка разделов загружается, когда статья готова его показать. Если читатель успел нажать «Разделы» в шапке, существующий стор хранит запрос до монтирования списка.

## Validation

Проверить прямой вход, переходы между статьями, поиск, возврат браузером и внутри приложения, сохранение серверной разметки и смену активного чипа. На опубликованной сборке измерить три холодных нажатия на каждое смещение из #3467 при load < 4. При нарушении истории, SSR или доступности вернуть коммит через штатный выкат.
