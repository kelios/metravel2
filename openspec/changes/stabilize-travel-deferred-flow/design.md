## Goals / Non-Goals

**Goal:** put normal-flow height ownership at the changing child boundary, using the existing measured-transition registry and its single ancestor-height/scroll-anchor transaction.

## Decisions

- In `TravelDetailsDeferred.tsx`, place the mounted map slot inside the shared measured-flow owner, keeping its existing placeholder and load condition. Once loaded, the isolated runtime can grow without changing sibling flow until its pre-paint measurement captures the visible following frame. The slot's internal map/points/excursions behavior stays owned by its existing component.
- In `sections/TravelDetailsMapSection.tsx`, wrap the whole existing `ExcursionsSection` child in the same configured owner, using existing window width and canonical tablet breakpoint. This boundary contains both the original 160px fallback and the complete real section/margin, so their replacement cannot move Map/Points before the leaf measurement joins its ancestors. Preserve eligibility, refs, force-visible props, iframe/loading behavior and the native pass-through. Retain the outer map owner for its other siblings. Preserve generic height publication and later/reserve-release paths; refine initial capture ownership as specified below.
- In `sections/TravelDetailsSidebarSection.tsx`, use the same transition around Nearby's content, with measurable empty runtime. Its existing loading/success/error/empty content stays visible; the transition can capture Popular or related navigation before changing its owned flow height.
- Retain the existing aggregate transitions: they own normal-flow heights of absolute ancestor runtimes and already join the leaf measurement transaction. Do not add a second correction algorithm. Existing no-op resize detection prevents repeated unchanged measurements.
- In the shared capture procedure, a child's first measurement in its current visible epoch checks ancestor payload ownership. If an ancestor's same-width runtime height differs from its last published measurement, its external reading frame has authority, including `null` when none is visible. A DOM-marked parent whose registration or baseline is not ready also supplies its external frame, so a fresh internal sibling cannot become fallback while parent geometry is unpublished. Height publication and ancestor reconciliation still run. The initial flag is read directly from `measuredHeightRef.current` at each commit; it is not frozen in a ResizeObserver closure. Reserve release retains its existing capture path.
- Restrict this new authority to the first measurement of the visible epoch, across all nested transitions. Applying height-difference authority to later transactions broke 22 existing Comments/reserve/slack controls: later ancestor differences can reflect already-owned nested flow or reserve release, while the captured sibling is an already-painted reading frame. A height difference alone cannot invalidate that frame. The narrowed rule preserves those controls and still removes the initial fresh-Map write; it is not a map/viewport branch or a skipped initial size commit. Existing visibility reset begins a new measurement epoch.
- `TravelDetailsMeasuredFlow` in the existing transition module owns the fixed contract shared by the map slot, Excursions replacement, Nearby and related navigation: controlled readiness, measurable zero height and no guessed reserve. Its typed callers provide only children, mobile geometry, test identity and optional pending/placeholder. They cannot accidentally combine internal readiness with an empty frame or introduce a reserve. It delegates directly to the shared generic transition and adds no DOM beyond that transition. Existing map loading, Nearby skeleton, related-navigation key and native pass-through are retained. This consolidates the measured-flow family without a new module or byte-only relocation; the Excursions composition reuses the same owner.
- Reject per-screen minHeight or permanently retaining the loading rail: they depend on content/locale and leave empty space. Reject a continuously sampled reading-anchor observer: it duplicates existing ownership and adds work across all frames.
- Query keys, endpoints, invalidation, article content, analytics, SEO and app text remain unchanged. Native's transition renders children directly and its separate deferred composition stays unchanged.
