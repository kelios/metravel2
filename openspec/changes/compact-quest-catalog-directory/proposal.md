## Why

На скриншоте владельца от 13.11.2026 указатель внизу `/quests` выглядит как несколько экранов сплошных ссылок. Живая проверка подтвердила наличие карточек выше; на 390 px один указатель занимает 3276 px высоты. Цель — компактная доступная навигация вместо постоянно раскрытого списка.

## What Changes

- Страны, города и квесты указателя становятся независимыми раскрывающимися разделами, закрытыми при открытии страницы.
- Все существующие ссылки остаются в серверном HTML и доступны без JavaScript по раскрытию раздела.
- Не меняются сетка, порядок квестов, фильтры, поиск и условия показа указателя.

## Capabilities

### New Capabilities

- `quest-catalog-directory`: компактные разделы ссылочного указателя с доступом мышью, касанием и клавиатурой, включая просмотр без JavaScript.

### Modified Capabilities

Нет.

## Impact

Platform impact: desktop web, mobile web; Android/iOS none — используется отдельный `.web.tsx`.
Localization impact: none — переиспользуются заголовки RU/BE/UK/PL/EN.
Scope: `screens/tabs/QuestsCatalogDirectory.web.tsx`, тесты серверной разметки, описание поведения в `docs/features/quests.md`, макет `docs/design/quest-catalog-directory.md`.
Dependencies: существующий discovery-loader; новые API и зависимости не нужны.
Fallback/mock policy: нативное раскрытие браузера без клиентского fallback; приёмка на реальном production-каталоге.
SEO: прежние href, состав и порядок ссылок в HTML, без отдельного скрытого индекса. URL/canonical/robots/sitemap/JSON-LD не меняются.
Accessibility: доступные заголовки разделов, штатная клавиатура браузера и область касания ≥44 px.
Performance: сокращается высота закрытого указателя, дополнительные запросы и клиентское состояние не требуются.
Security/analytics: изменений нет, используются прежние внутренние ссылки, события не добавляются.
