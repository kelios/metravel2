## Why

Карточки #2855/#2856 продолжают общую модель визуальных редакций #2854.
Для фэнтези уже подготовлены все 61 иллюстрация BY31/PL30; графический вариант
имеет отдельный образец, ожидающий решения владельца. Копия книги или рендера
для каждого стиля потеряет единый состав, ревизии и происхождение изображений.

## What Changes

- Сохранить в tracked-данных одобрение фэнтези, точные промпты/источники всех
  иллюстраций и статический лицензированный Cormorant Garamond.
- Сохранить один durable графический образец с `approved=false` до решения
  владельца. Создание серии не следует из наличия файла образца.
- Добавить один loader производных иллюстраций, потребляющий уже проверенные
  stop/source записи общего `loadSelectedBook`, а не повторяющий их отбор,
  редакционный текст, QR, пагинацию или рендер.
- После освобождения E1 shared-файлов подключить этот loader к существующей
  точке выбора стиля, добавить стиль в общий copy/metrics и собрать через
  существующие render/validation/publication команды.

Внешний uploader, новый API, замена фотографий, live-статьи, облачный рендер
и повышение пиксельного разрешения не входят в изменение.

## Capabilities

### New Capabilities

- `illustrated-book-inputs`: проверенные source/derivative/font/approval входы
  для общей сборки нескольких иллюстративных стилей.

### Modified Capabilities

Готовые книги сохраняют country+visualStyle+revision, текущие три страницы
на место, два обязательных QR и подтверждённые optional quest, чистые страницы,
четыре стороны обложки и финальную карту.

## Impact

Новые style-specific records/assets, локальный helper, focused source tests;
затем только необходимые shared style wiring и публикационные метаданные.
Редакционные PDF — RU; существующие UI style labels уже поддерживают все
пять локалей. Отдельные native-файлы не затрагиваются.
