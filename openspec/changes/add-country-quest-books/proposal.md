## Why

Владелец уточнил #2808: нужны страновые фотодневники по нашим онлайн-квестам,
а не отдельные печатные прохождения с player/host. Книга помогает выбирать
квест, проходить его по QR, сохранять фотографии и собственные заметки.

## What Changes

- Беларусь и Польша получают отдельные серии с частями. Полный опубликованный
  каталог учитывается в отборе: на31.10.2026 BY82/PL73, без пропущенных или
  повторённых ID. Предложение части1: BY41 (38городов+3дополнительных маршрута),
  PL37 (несезонные); остальные BY41/PL36 зарезервированы части2.
- На квест четыре страницы/два разворота: сюжет и все точки; карта маршрута;
  свободная фотография; свободные заметки. Используются существующая обложка
  и QR на точный опубликованный онлайн-квест. Общая аудитория не назначается:
  исходные возраст/сложность/сезонность сохраняются для каждого квеста.
- Удаляется ошибочная неопубликованная подготовка двух одиночных пилотов
  Mir/Torun/player/host. История коммита3e6e4baf9 остаётся в Git и на борде.
- Новый kind/series/volume интегрируется в существующий каталог, PDF/preview,
  скачивания и физические профили. Данные книг загружаются из SHA-проверяемого
  статического JSON, чтобы не раздувать начальный JavaScript.
- Концовка утверждена владельцем01.11.2026: «Общая карта страны со всеми
  квестами». Включены квесты текущего тома; ключ ответов не добавляется.

## Capabilities

### New Capabilities

- `country-quest-books`: страновые серии фотодневников по опубликованным
  онлайн-квестам, с четырёхстраничным блоком, частями и полной картой отбора.

### Modified Capabilities

Нет изменения пользовательского контракта прежних книг мест. Их min30,
три страницы/место, исходники автора1 и старые URL сохраняются.

## Impact

Scope: `data/travelBooks/quests/**`, `services/book/readyBooks/**`,
`scripts/books/**`, `components/books/**`, `i18n/locales/*/books.ts`,
профильные tests, feature/design docs и этот change. Точные пути фиксируются
по мере независимых source/render/catalog блоков; чужие правки не включаются.
Platform impact: локальный общий PDF-движок; mobile web→desktop web для
публичного каталога/preview/download. Native/store не меняются.
Localization impact: книги RU; новые UI-ресурсы RU/BE/UK/PL/EN через books.
Data/API impact: read-only published quest API; новый статический kind/series/
volume, версия и SHA ресурсов; backend не меняется.
SEO impact: новые собственные slug проходят существующие book routes;
старые URL сохраняются. Accessibility: подписи QR/карт, читаемый шрифт,
клавиатура и ошибки прежнего viewer. Performance: без начальной загрузки PDF,
не больше3preview в первом окне; metadata не встраивается целиком в JS.
Security: экранирование всех API/editorial строк, проверка URI/bytes/SHA,
без user counters/PII, приватных job API или передачи данных провайдеру.
Analytics: существующая воронка books без нового смысла «заказ» или PII.

Dependencies: опубликованный состав, реальные covers и точки, согласованная
концовка/макет; цифровая и физическая приёмки различаются. #2807 не блокирует
правильно уточнённый результат: прежний запрет относился к ошибочной трактовке.
Non-goals: изменение живых квестов, перепечатка всех заданий на основных
страницах, новые квесты/иллюстрации, платная печать, переписка, AWS/cloud/stores.
Fallback/mock policy: fixtures только unit; отсутствующее покрытие/карта/медиа
не заменяется выдуманными данными. Схематичная линия не объявляется пешим путём.
