## Why

В #2198 опубликованная пометка языка уже находится рядом с маршрутом, но общий закреплённый ряд не учитывает высоту телефона. Независимая приёмка 07.10.2026 получила на 320×640 firstContentTopRatio=0.190625 и pinnedChromeRatio=0.253125 при неизменных пределах 0.155/0.197; на 390×844 те же 122/162 px проходят. Это подтверждённый конфликт responsive-контракта, а не дефект перевода.

## What Changes

- Ввести короткую компоновку прохождения квеста: на compact-phone с высотой окна менее 840 CSS px единственный ряд маршрута и языка становится первым элементом существующей прокрутки. При высоте 840+ обычное закреплённое размещение сохраняется.
- На коротком экране сохранить видимый до прокрутки маршрут, полное название языка, пассивную пометку отдельно от кнопки, цели касания не меньше 44 px и отдельные статусы pending/photo.
- Сохранить строку заголовка, действия, док, прогресс и единственную прокрутку. Смена компоновки не должна прерывать ввод, закрывать открытый лист или менять точку маршрута.
- Закрепить постоянные сценарии короткой/обычной высоты и независимую production-приёмку по прежним метрикам. Расчёт 98/110 px для короткой компоновки — проектная оценка, не результат QA.

Goal: на существующих контрольных 320×640 и 390×844 без pending/photo получить firstContentTopRatio≤0.155 и pinnedChromeRatio≤0.197 без ослабления проверок.

User-visible result: на коротком телефоне ряд маршрута прокручивается вместе с заданием и доступен при возврате вверх; на обычном телефоне он остаётся закреплённым.

Existing behavior to preserve: RU, переведённые и иностранные квесты; guest/auth/offline; полный лист маршрута, счётчики, интро/шаг/финал, фото и pending; обычная высота, tablet/desktop, клавиатура и действия экрана.

Non-goals: перевод/авторский текст, API/cache/progress-протокол, глобальная шапка и док, новые локальные подписи, native-specific изменения, видео, поиск/печать/шаринг, бюджеты и семантика измерителей.

## Capabilities

### New Capabilities

- `quest-responsive-shell`: компоновка прохождения квеста по доступной высоте, доступность маршрута и устойчивость состояния при смене размеров окна.

### Modified Capabilities

Нет: существующие living specs progress reconciliation и sidebar не меняются. Этот change дополняет опубликованную локализацию отдельным responsive-контрактом; исходный change `add-quest-content-localization` сохраняется.

## Impact

Platform impact: shared responsive layout; обязательные desktop web1440 и mobile web320×640/390×844. По действующему контракту #2198 native runtime не входит в приёмку; отдельных Android/iOS веток не добавляется.

Localization impact: all current locales — RU/BE/UK/PL/EN; переиспользуются текущие ключи и форматирование, без новых авторских строк.

Dependencies: жёсткой backend-зависимости у размещения нет. #2197 done; #2193 done по актуальной карточке 08.10; опубликованный контракт принят отдельной приёмкой. Отсутствующий перевод определяется реальными contentLocale/availableLocales, не скрывается моками. Применение требует отдельного запроса пользователя после просмотра этих artifacts по AGENTS.md и OpenSpec planning boundary.

Fallback/mock policy: unit может изолировать внешние модели, но production использует настоящие квесты и API. RU/translated/foreign/offline preconditions проверяются на день приёмки; исторический Luxembourg PL fallback не принимается за актуальный. Guest fixtures не доказывают настоящее прохождение.

Code ownership: quest responsive model, wizard/shell/styles и минимальная доменная связь состояния route/input, meaningful tests, feature docs. Глобальные viewport/header/dock providers и API не меняются.

Data/API: форма запросов, contentLocale/availableLocales, запись ответов и telemetry неизменны. SEO: URL/canonical/SSG/robots/sitemap неизменны. Accessibility: сохранены полные подписи и 44 px цели; требуется проверка фокуса/листа при resize. Performance: без новых запросов/медиа, один ScrollView; исключить повторное монтирование задания и скачки при прокрутке. Security: ввод/URL/auth не меняются. Analytics: события и их producer ownership сохраняются.

Apply authorization: отдельный запрос владельца по #2198 «делай» получен 08.10.2026 после предъявления artifacts; граница 840 px и перенос маршрута приняты в этом apply. 640 px — нижняя высота существующего бюджетного контроля; более низкие окна должны оставаться работоспособными, но нового обещания этих ratios для них нет. Подтверждённый FAIL не переименовывается в PASS за счёт этого ограничения.
