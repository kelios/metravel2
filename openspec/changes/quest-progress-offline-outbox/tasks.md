## 5. Тесты

- [ ] 5.1 Тест очереди: запись переживает «перезапуск» (перечитывание из хранилища), повторная постановка заменяет запись, потолок соблюдается
- [ ] 5.2 Тест доставки: успешная доставка снимает запись; ошибка оставляет её и планирует повтор
- [ ] 5.3 Тест авторизации: без авторизации досылка не ходит в сеть и НЕ очищает очередь; после входа запись уезжает
- [ ] 5.4 Сценарный тест: прохождение офлайн → уход с экрана → «перезапуск» → сеть → на сервере есть прохождение без открытия экрана квеста
- [ ] 5.5 Тест адресности: снапшот одного квеста не уходит другому, несколько квестов доставляются каждый своим запросом
- [ ] 5.6 Тест пометки: состояние «не отправлено» появляется по записи в очереди и исчезает после доставки
