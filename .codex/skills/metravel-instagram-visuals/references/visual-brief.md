# Source-grounded visual brief

## Manifest

For each slide record:

| Field | Purpose |
| --- | --- |
| `slide` / `text` | Exact ordinal and approved text |
| `source_url` / `source_field` | Article or quest/step and supporting fragment |
| `place` / `anchors` | Verified visible landmark details that identify the scene |
| `reference_path` / `provenance` | Inspected owner/site/licensed photograph or quest art |
| `medium` | Documentary photo, illustration or composite |
| `audience` | Catalog age/family tags, task language/mechanics, and the owner's requested visual age |
| `scene` / `motif` | What happens here and the supported legend clue |
| `generation_prompt` / `output_path` | Reproducible art prompt and actual output |
| `review` | Match, defect, fix and final checked file |

Use verified route coordinates for diagrams. Decorative clue trails may be
illustrated, but label them as schematic and do not imply geographic accuracy.
Public promotion can show task mechanics without exposing the correct answers.

## Scene prompt template

Replace bracketed inputs from the manifest; omit anything unverified. Feed
inspected reference images to imagegen using its supported reference mechanism.

```text
Create a [aspect] editorial illustration for the MeTravel Instagram carousel
about [verified city and quest title]. This is illustrated campaign art.
Depict [verified step location and activity], matching the supplied landmark
reference in [confirmed visible architectural/landscape anchors].
The main story is a real walking quest: [observable clue-finding activity].
Use [supported legend motif] as [small secondary visual cue], with [season,
palette, light and style shared with the other slides]. Keep [layout area]
clear for exact typography added separately. No lettering in the generated art.
Exclude invented buildings/monuments, unrelated skylines, navigation maps,
spoiler answers and documentary-photo styling. Preserve the referenced place's
recognizable geometry and proportions.
```

For a scene involving Minsk's Цмок, the prompt's location must come from its
actual step bundle. A small river-dragon shadow, ripple or clue can carry the
legend when supported by the story; a giant fire-breathing monster amid medieval
houses changes the advertised experience and fails the match check.

## Carousel consistency and review

Use one style brief for all scenes, but let every slide show a distinct
confirmed location or activity. City identity should remain visible after the
title is hidden. The cover sells the walking experience; middle slides show
the real route and task mechanics; the closing slide supports the existing CTA.

For each final slide inspect the image at full size and mobile preview size:
correct place, absence of invented details, exact reused text, coherent crop,
legibility, identical dimensions, footer and numbering. Inspect the contact
sheet for repetitive scenes and abrupt palette shifts. If an anchor cannot be
made reliable, choose another verified reference or an openly abstract
illustration; do not pass a plausible-looking invented landmark.
