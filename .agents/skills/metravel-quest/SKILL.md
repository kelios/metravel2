# metravel-quest

Регламент городских квестов metravel.by. Квест — пеший маршрут по точкам
города: на каждой точке игрок читает живую историю и выполняет задание,
выполнимое стоя перед объектом. Это ядро: полномочия, роли, жёсткие числа,
запреты и конвейер. Подробности — в `references/` (карта внизу); открывай
нужный файл, а не все сразу.

## Полномочия

Единственный источник полномочий по контенту квестов; агенты и брифы ссылаются
сюда, а не пересказывают. Исключения из общего правила AGENTS.md («creative
prose только после подтверждения») записаны в AGENTS.md → §4.

- **Заказ = полный цикл до прода** (правило владельца 11.10.2026). «Сделай /
  подготовь квест(ы)», «добавь финал/обложку» — это заказ: данные → ревью →
  зелёный `quest:gates` → `migrate-quest-from-file.js --apply` → GET-сверка →
  выкат фронта → приёмка → `done`. Отдельного «да» на заливку заказанного
  квеста, его финала, видео и обложки не нужно. Правка по прямому заказу
  владельца на конкретный опубликованный квест — тоже заказ.
- **Рискованный вопрос агент решает сам** (05.10.2026, дважды): нет 100%
  уверенности в единственном ответе (честный игрок ответит иначе, эталон может
  устареть, есть второй верный ответ) — шаг переводится в `any_text` в сюжете
  квеста или на действительно очевидный вопрос, а `task`/`hint` такого шага
  правятся без вопроса владельцу. В отчёте — «было → стало», не вопрос.
  Расширение словаря синонимами при оставшейся двусмысленности — не решение.
- **Подтверждение владельца нужно только для:** правки авторского текста
  (story/task/hint/title/intro/finale) уже опубликованного квеста по
  собственной инициативе агента (аудит сам по себе правку не разрешает);
  снятия квеста с публикации или удаления шагов; квеста в новом городе, если
  `quest:gates` показал alias-риск (#2209). Уже данное подтверждение повторно не
  запрашивается.
- Доказательства не заменяются выбором модели: наблюдаемая деталь подтверждена
  источниками и фото, точка — гео-проверкой.

## Кто что делает

| работа | исполнитель |
|---|---|
| новый квест: ресёрч + data-файл | субагент `general-purpose` с `model: "opus"` по `references/author-brief.md`; только Opus; ≤4 разом |
| оркестрация, ревью сдачи, перенос в `scripts/`, заливка, шаги после | сессия, получившая заказ (этот скилл) |
| правка опубликованного: story/task/hint, тон, авторский `answer_pattern`, poi_info | `quest-editor` по `references/live-edit.md` |
| `answer_pattern` по реальным попыткам игроков, разбор трения | `quest-friction-analyst` |
| координаты и геометрия маршрута (только патч) | `quest-geo-verifier` по скиллу `metravel-quest-geocheck` |
| перевод и смысловая проверка перевода | `quest-translator` |
| финал: видео и постер | скилл `metravel-quest-finale` |
| код движка, сканы, миграции (`components/quests/**`, `scripts/*quest*.js` кроме `*-quest-data.js`) | `quest-expert` |

`scripts/*-quest-data.js` — контент, а не код: его меняют автор (до заливки),
`quest-editor` и `quest-friction-analyst` (синк после правки на проде).

## Источники: Беларусь и Польша (правило владельца 11.10.2026)

- **Беларусь.** Ни в одном тексте квеста (и досье в `docs/`) нельзя
  цитировать, упоминать и ссылаться на ресурсы из перечня экстремистских
  материалов РБ: «Наша Ніва», «Зеркало» (бывший TUT.BY), «Радыё Свабода»,
  «Белсат», «Еврорадио», «Хартия'97», «Наш Край», «Салідарнасць», «Белорусский
  партизан», «Новы Час» и подобные; не опирайся на них и в ресёрче. Легенда,
  известная только по такому пересказу, — «по поздним пересказам краеведов» без
  указания источника; сам факт ищется в книге (Бохан «Минские предания и
  легенды», 1901), музее, краеведческом издании, энциклопедии, госСМИ («СБ»,
  БЕЛТА, областные газеты). Проверка — `node scripts/scan-content-sources.js
  <файл>` (входит в `quest:gates`), ноль попаданий. Политики в квестах нет.
- **Польша.** Опора для легенд замков и монастырей — Zenon Gierała, «Zamki i
  klasztory w legendach i baśniach polskich» (есть у владельца): брать из неё
  основу, ссылаться в story, где уместно; дополнять ею существующие квесты.

## Жёсткие числа

| что | норма |
|---|---|
| точек (взрослый, любой формат, вкл. roadtrip/вело) | 8–12, пол 8; детские 6–8 (5-7), 7–9 (8-10), подростки 8–10 |
| запас якорей до маршрута | <8 проверяемых на месте объектов — это статья, не квест |
| обязательных шагов с проверяемым ответом | ≥6 (`exact`/`exact_any`/`range`/`approx`); детские — по `kids.md` |
| `any_text` среди обязательных | ≤3; `min_length` 4–10 |
| маршрут пешком | сумма перегонов по прямым ≤4 км, перегон ≤1,2 км; зимняя волна 3,5/1 км; детские ≤1,5 / ≤2,5 км |
| геометрия | цепочка или кольцо, без возвратов (порог 150 м); крюк точки ≤150 м и ≤25% |
| привал | с именем, в середине, крюк <250 м; маршрут ≥2 ч — обязателен |
| мемориальных точек | ≤1–2 на квест, не подряд, старт и финал светлые |
| story точки | ≥4 предложений; ≥300 слов на посадочной и детальной, цель ≥380 |
| источники | нетривиальный факт — 2 независимых; проверяемый ответ — 2 фото, одно не старше 2020; цвет/облицовка — датированное фото ≤3 лет |
| счёт | одно число из 2 источников; `range` ±1 только при n≥3 и границе счёта в задании |
| пересечение с квестами города | ≤1–2 точки, ответ другой |

## Планка вопроса

Все четыре: ответ 100% однозначен и проверяем; виден стоя на точке; не выдан
в story/hint/title/location/интро/заголовке квеста; объект стабилен круглый год.
Типы — (A) культовая вещь места, (B) надпись/дата/имя на объекте, (C)
спрятанная стабильная деталь, (D) что изображено и что значит. Источник
ответа — текст самого объекта, OSM `name` — нет. Нет 100% — свободный ответ
(см. «Полномочия»). Подробно — `references/questions.md`.

## Запреты

- Смерть как арифметика: «сколько погибло/похоронено», «год смерти», «сколько
  прожил».
- Ответ из цвета или облицовки без датированного свежего фото (4f).
- Ответ с фонтана, с земли и ступеней, мелкая надпись выше 3 м, живое дерево,
  вывеска арендатора, сезонное украшение.
- Ответ в подсказке, заголовке, location, story своего и соседнего шага,
  интро, `quest.title` и `quest_id`; короткое число/слово, сливающееся с другими
  словами текста.
- Счёт нестабильного, термины-загадки, субъективное, эрудиция «из кресла»,
  вопросы-определения для подростков.
- «Нажми „Пропустить“» на проверяемом шаге; кнопки, которых нет в мастере.
- Выдуманная наблюдаемая деталь; точка-тема без объекта; закрытый объект.
- Транспорт между точками пешего квеста; возвраты по маршруту.
- Смена `quest_id`/`step_id`/`storage_key` опубликованного квеста.
- Черновик в `scripts/` (роняет общий pre-commit, #2228); заливка без зелёного
  `quest:gates`.
- Самодельные обложки и PIL-плейсхолдеры (обложку генерирует Codex по PROMPT.md).
- Ресурсы из перечня экстремистских материалов РБ; чужие бренды в детских.
- Токен в выводе, в чате, в командной строке.

## Конвейер нового квеста

1. Слой и сюжет: обойти `GET /api/quests/` по `next`, выписать точки квестов
   города, выбрать слой, которого нет (`research-route.md`).
2. Ресёрч «самое-самое» и счёт якорей до маршрута; <8 — статья.
3. Автор (Opus по `author-brief.md`) пишет
   `.codex-temp/quests-plan/<city>/<quest_id>-quest-data.js` и PROMPT.md обложки.
4. `npm run quest:gates -- --source=<черновик>` — выход 0 (dry-run миграции,
   все `scan-quest-*`, маршрут, источники РБ, самоутечка, доля проверяемых,
   короткие ответы, alias города).
5. `node scripts/quest-geocheck.js --source-file=<черновик> --quest-id=<id>` —
   разобрать WARN/FAIL (скилл `metravel-quest-geocheck`).
6. Ревью оркестратора по `questions.md`; правки — снова шаг 4.
7. Перенос в `scripts/<city>-quest-data.js`, `quest:gates` по новому пути.
8. `migrate-quest-from-file.js --dry-run`, затем `--apply`: `status=1` — квест
   сразу опубликован. GET-сверка, sitemap для нового города.
9. Переводы, обложка (Codex), финал-видео, перелинковка — `upload-after.md`.
10. Коммит data-файла явными путями, выкат фронта, приёмка на проде, `done`.

Правка опубликованного квеста — `references/live-edit.md`.
