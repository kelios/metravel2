# Аудит статьи до правки

`GET /api/travels/{id}/`, `description` — в файл, прочитать ЦЕЛИКОМ; затем
`node scripts/article-acceptance-check.js --id <id>` — машинная часть ниже
(помечена ⚙) приходит готовым списком. В старых статьях что-то находится почти всегда.

| Что искать | Как проявляется | Что делать |
|---|---|---|
| ⚙ `alt="Изображение"` / пустой alt | так сохраняет визард | описать кадр с точки зрения места |
| ⚙ Люди в подписях | «Юля», «муж», «мы», «селфи» в alt и `gallery[].caption` | переписать на место |
| ⚙ Пустые подписи галереи | `gallery[].caption` = '' | проставить (`photo-pipeline.md`) |
| ⚙ Дубли кадров | один снимок дважды под разными `<hash>` (md5 или dhash) | удалить весь `<p>` лишнего |
| ⚙ `address-image` в теле | ссылка на фото точки | перезалить в `collection=description` |
| ⚙ Два или ноль «Что рядом» | второй приклеен снизу | оставить один, найти соседей (`body-html.md`) |
| ⚙ Нет блока квестов | между «Что рядом» и FAQ пусто | добавить (`body-html.md`) |
| ⚙ Нет комментария редакции | или он от user ≠ 120 | `editorial-comment.md` |
| ⚙ Дата ≠ поездка | `created_at` = день импорта; `month` пуст | `live-edit-recipes.md` → «Дата» |
| ⚙ Сырые имена точек | «Krakowska 149», «964», «S7», одно имя ×5 | переименовать |
| ⚙ Приватные данные | скриншот брони, `sid=`/`checkin=` в ссылке | убрать, `aid=`/`label=` оставить |
| ⚙ Запрещённые источники BY | «Наша Ніва», «Зеркало»… | убрать, факт — из книги/музея/госСМИ |
| ⚙ Мусор и маркеры | `[уточнить]`, `__draft_placeholder__`, U+FFFD, `utm_source=chatgpt.com`, Instagram-iframe | вычистить / заменить ссылкой на reel |
| Дубль практического блока | два раздела с ценами/часами и РАЗНЫМИ цифрами | один «Если соберётесь» |
| Расхождения чисел | «72 км» во вступлении и «55 км» в хвосте | свести к одному набору |
| Автор в третьем лице | «Julia права» в FAQ | первое лицо |
| Мусор разметки | `<h2><br /></h2>`, `<span></span>` в `<li>`, `<p><br /></p>`, одноэлементные `<ol>`, `<strong> </strong>` | вычистить |
| Справочные разделы против 2d | «Сложность маршрута», «Что взять с собой», «Что посмотреть по дороге», координаты под заголовками | вплести в рассказ / в «Если соберётесь» |
| AI-обороты | «не просто …, а …», «именно», «настоящий», «одна из самых», жирный на каждом названии | вычистить |
| Текст без фото | описаны янтарь/трапезная, а снимков нет | главный повод «добавить фото» |
| Нет FAQ | | `body-html.md` → FAQ |
| Внутренняя ссылка 301 | слаг переименован | канонический слаг из `redirect_url` |
| Нет связанных статей | свои статьи про тот же массив есть, ссылок нет | «Что рядом» |
