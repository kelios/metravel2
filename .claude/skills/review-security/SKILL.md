# review-security

Для ревью безопасности фронтенда следуй каноническому
`.codex/skills/metravel-security-reviewer/SKILL.md`. Он задаёт поверхности
проверки, допустимые доказательства и формат находок. При ревью diff проверь
изменённые пути и их потребителей. Полный аудит охватывает весь заказанный
scope. Режим обычного ревью — чтение; по запросу «исправь» добавь исправление
и регрессионную проверку.

Если нужна независимая проверка, передай `review-auditor` конкретный поток
данных и выбранный режим. Серверную находку привяжи к владельцу `area=back`
с доказательством без значений секретов (`docs/TASK_BOARD_MCP.md`).
