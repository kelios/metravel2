# Комментарий редакции под статьёй

Под каждой статьёй — ровно один комментарий от «Редакция metravel» (user 120) в
блоке комментариев (`components/travel/CommentsSection.tsx`, `/api/travel-comments/`),
не в теле. Задача — расшевелить обсуждение: бывавший там человек должен понять,
о чём именно его спрашивают, и захотеть ответить.

## Запись

Сначала проверить: `curl -s "https://metravel.by/api/travel-comments/tree/?travel_id=<ID>"`.
Комментарий редакции есть — не дублировать, править его:
`editor.request('/api/travel-comments/<commentId>/', {method: 'PATCH', json: {text}})`.
Новый — `POST` с `travel_id` (главный тред создаётся сам).

Автор берётся из токена, поэтому нужен профиль editor120, не owner1 (решение
владельца 21.09.2026: все комментарии редакции — от редакции):

```js
const { createToolSession } = require('./scripts/lib/metravel-tool-session');
const editor = createToolSession({ profile: 'editor', expectedUserId: 120,
  order: ['editorEnv', 'editorHome'] });
await editor.request('/api/travel-comments/', {
  method: 'POST', json: { travel_id: ID, text: commentText } });
```

Ответ — `201` + `{id, thread, user: 120, user_name: "Редакция metravel"}`.
Другой `user` — комментарий ушёл не от того аккаунта: `DELETE` и повторить
верным профилем. Аккаунт 120 — постоянный reviewer-аккаунт Apple App Review
(`docs/WORKFLOW_OPERATIONS.md` §3.1): не удалять, логин/пароль не выводить
нигде. Токены owner1 и QA104 для комментариев не годятся.

## Как писать

- 2–4 коротких абзаца, голос редакции от первого лица множественного числа
  («мы шли», «у нас вышло»), без «я»;
- конкретные вопросы вместо «делитесь мнением»: попал ли внутрь, в каком месяце
  ездил, что было открыто, как днём и вечером, каково с детьми или собакой;
- зацепиться за то, что устаревает: стройка, сезонное расписание, ремонт музея,
  цены — повод написать именно сейчас;
- обещание, которое выполняется: «напишите — дополним статью»; факты из ответов
  потом реально вносятся в текст;
- редакционную выноску из тела не повторять: в теле — рамка к материалу, в
  комментариях — приглашение к разговору.
