description: "Независимое код-ревью frontend-задачи перед testing или чтение текущего diff без тикета."
---

Передай независимому ревьюеру полный diff, пути задачи, затронутые платформы и результаты проверок. По `AGENTS.md` §4.6 малый diff проверяет `code-review-gate`. Остальные сначала проверяет `review-auditor`, затем итоговый diff получает `code-review-gate`.

Аргументы `$ARGUMENTS` определяют результат:

- Без ID проверь текущий diff, включая незакоммиченные и новые файлы, и верни замечания и вердикт в чат.
- При наличии ID прочитай карточку и Task Contract. Backend-карточку передай владельцу backend checkout. Во фронтенде `changes_requested` возвращает карточку в `in_progress` с findings. После `pass` зафиксируй только проверенные пути и запиши SHA после push по разделу «Коммит и пуш — часть перехода `review → testing`» в `docs/TASK_BOARD_MCP.md`. В `testing` агент `board-reviewer` проверяет платформы и среду из Task Contract.

Повторный запуск нужен после правки проверенного кода или истечения вердикта. Состояние гейта для карточки показывает `node .claude/hooks/review-gate.mjs show --task <id>`.
