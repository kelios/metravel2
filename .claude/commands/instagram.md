Ты запускаешь ведение Instagram @metravelby. Делегируй работу агенту `instagram-editor`
через Agent tool (`subagent_type: "instagram-editor"`), затем выведи его отчёт пользователю
как есть.

Режим — из аргумента `$ARGUMENTS`: `brief` (по умолчанию, что делать сегодня), `pack`
(ролики и карусель на неделю), `reel <дата или тема>` (смонтировать ролик из живых клипов архива по
`docs/INSTAGRAM_REELS_BRIEF.md`), `publish <пост>` (опубликовать или поставить в расписание
утверждённый пост),
`review` (разбор статистики за 7 дней и затем `pack`), `cleanup` (порция чистки подписчиков
по числовым критериям агента).

Контекст для агента (передай дословно):
- Рабочий каталог репо: корень текущего чекаута (`$CLAUDE_PROJECT_DIR`, на этой машине
  `~/Sites/metravel2/metravel2`).
- Источник правды — `docs/INSTAGRAM_PLAN.md`; читать нужным разделом.
- Контент только по опубликованным статьям автора 1 (`userIds == "1"`); гостевые статьи не
  использовать; числа — только из текста статьи.
- Браузерная панель — сессия владельца @metravelby: только чтение, кроме удаления
  подписчиков в режиме `cleanup` по порядку и лимитам из файла агента (решение владельца от
  04.10.2026; на кого она подписана — не трогать). Публикация, лайки, комментарии, директ —
  только после явного «да» владельца в чате на конкретное действие.
- Владелец ничего не готовит сама (05.10.2026): исходники, монтаж, хук, карусели, подписи и
  расписание — на агенте; ей — список недостающего и «да» на конкретный пост.
- Расписание публикаций владелец смотрит на https://www.instagram.com/scheduled_content/
  (там же можно планировать через браузер); задачи компьютера — приложение Claude → боковая
  панель → «Запланированные». Один пост не ставить двумя путями без защиты от повтора.
- Сегодняшнюю дату взять командой `date +%F`.
