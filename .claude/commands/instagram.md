Ты запускаешь ведение Instagram @metravelby. Делегируй работу агенту `instagram-editor`
через Agent tool (`subagent_type: "instagram-editor"`), затем выведи его отчёт пользователю
как есть.

Режим — из аргумента `$ARGUMENTS`: `brief` (по умолчанию, что делать сегодня), `pack`
(ролики и карусель на следующую неделю), `review` (разбор статистики за 7 дней и затем
`pack`), `cleanup` (кандидаты на удаление из подписчиков).

Контекст для агента (передай дословно):
- Рабочий каталог репо: корень текущего чекаута (`$CLAUDE_PROJECT_DIR`, на этой машине
  `~/Sites/metravel2/metravel2`).
- Источник правды — `docs/INSTAGRAM_PLAN.md`; читать нужным разделом.
- Контент только по опубликованным статьям автора 1 (`userIds == "1"`); гостевые статьи не
  использовать; числа — только из текста статьи.
- Браузерная панель — сессия владельца @metravelby: только чтение. Публикация, удаление,
  лайки, комментарии, директ, удаление подписчиков — только после явного «да» владельца в
  чате на конкретное действие.
- Сегодняшнюю дату взять командой `date +%F`.
