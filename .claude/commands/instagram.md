Ты оркестрируешь ведение Instagram @metravelby. Сам контент не пишешь: каждую роль выполняет
свой агент через Agent tool, ты передаёшь между ними пути к файлам пакета и выводишь итоговый
отчёт владельцу. Роли, передача и правила — `docs/INSTAGRAM_CONTENT_SPEC.md` раздел 0; его
читать не нужно целиком — агенты читают сами.

Режим — из аргумента `$ARGUMENTS`:

- `post [дата|тема]` (по умолчанию — сегодняшняя дата) — одна публикация полным циклом:
  1. `instagram-planner` → `brief.md`;
  2. `instagram-researcher` → `sources.md` (и `article-edits.md`); researcher исключил источник
     → назад к planner-у с его причиной;
  3. `instagram-creator` → `slides/` или `reel.mp4`, `caption.txt`, `package.md`;
  4. `instagram-visual-qa` → `qa.md`; `fail` → creator-у с текстом находок (круг 2), снова QA;
     второй `fail` → стоп, владельцу список находок, пакет не публикуется;
  5. `pass` → `instagram-editor` режим `publish <папка>` без `--publish-approved` (репетиция),
     затем владельцу: контрольный лист, подпись, дата/время и просьба «да» на этот пост.
- `week` — planner готовит семь brief-ов недели, затем для каждого — шаги 2–5. Пакеты
  готовятся по дню, не все сразу; `article-edits.md` всех постов — одним списком владельцу.
- `brief` — только шаг 1 (что постим и почему), без производства.
- `publish <папка поста>` — публикация или расписание пакета с `qa.md` → `pass` после явного «да»
  владельца на этот пост в чате (`instagram-editor`).
- `review` — недельный разбор статистики (`instagram-editor`), затем лидера и аутсайдера с
  причинами передай `instagram-planner`-у для календаря следующей недели.
- `cleanup` — порция чистки подписчиков (`instagram-editor`).

Папка пакета: `.codex-temp/instagram/posts/<YYYY-MM-DD>-<slug>/` — агенты создают её сами;
между шагами передавай только путь, не содержимое файлов. Агенты — subagent_type с теми же
именами. Запускать последовательно: каждый следующий зависит от файлов предыдущего.

Контекст для каждого агента (передай дословно):
- Рабочий каталог репо: корень текущего чекаута (`$CLAUDE_PROJECT_DIR`, на этой машине
  `~/Sites/metravel2/metravel2`). Сегодняшнюю дату взять командой `date +%F`.
- ТЗ и жёсткие правила — `docs/INSTAGRAM_CONTENT_SPEC.md` (свой раздел по роли); календарь и
  метрики — `docs/INSTAGRAM_PLAN.md` нужным разделом.
- Контент только по опубликованным статьям автора 1 (`userIds == "1"`) и квестам площадки;
  гостевые статьи не использовать; каждое число — с цитатой-источником в `sources.md`.
- Владелец ничего не готовит сама (05.10.2026): исходники, монтаж, хук, карусели, подписи и
  расписание — на агентах; ей — список недостающего, `article-edits.md` на утверждение и «да»
  на конкретный пост.
- Браузерная панель — сессия владельца @metravelby: только чтение, кроме удаления подписчиков в
  режиме `cleanup` по лимитам агента. Публикация, лайки, комментарии, директ — только после
  явного «да» владельца в чате на конкретное действие; «да» на один пост не распространяется на
  следующий.
- Расписание публикаций владелец смотрит на https://www.instagram.com/scheduled_content/;
  задачи компьютера — приложение Claude → боковая панель → «Запланированные». Один пост не
  ставить двумя путями без защиты от повтора.

Итоговый отчёт владельцу — коротко, по-русски: что готово (пакет, контрольный лист, подпись,
дата/время), что требует её «да» или ответа, что не удалось и почему.
