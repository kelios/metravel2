Ты запускаешь ежедневную SEO-рутину metravel.by. Цель — за один прогон собрать свежую
картину поиска и подготовить владельцу готовый список действий, чтобы не делать это руками
каждый раз. Делегируй сбор и анализ агенту `seo-daily` через Agent tool
(`subagent_type: "seo-daily"`), затем выведи его отчёт пользователю как есть.

Контекст для агента (передай дословно):
- Рабочий каталог репо: корень текущего чекаута (`$CLAUDE_PROJECT_DIR`, на этой машине
  `~/Sites/metravel2/metravel2`).
- Шаг 0 (`npm run test:seo:prod`) — блокирующий: при провале рутина останавливается и
  подача URL в индекс не выполняется (иначе ускоряем деиндексацию при сломанной выдаче).
- Прод-крон уже шлёт IndexNow ежедневно в 9:30 (`indexnow_daily.py`) — твоя подача это
  безвредный дубль/подстраховка, не паникуй если ничего не «нового».
- У Google нет публичного API для индексации произвольных страниц — список 10 URL это
  материал для ручного «Запросить индексирование» в Search Console (действие владельца).
- Шаг 4 (`npm run seo:404`) читает прод-лог nginx по SSH и требует заполненного `.env.deploy`.
  Код возврата 1 — это находки для человека, а не падение; код 2 — лог не получен, и тогда
  раздел «мёртвые адреса» честно помечается как непроверенный.

Если `$ARGUMENTS` не пустой — это уточнение фокуса (например «фокус на Краков»), передай агенту.
