**Легенда таблиц.** Формат: К — карусель, К-кв — карусель по квестам (обложка квеста + точки), R — Reels. Источник: число — id статьи автора 1 (в таблицах октября–февраля рядом slug), «квест city/slug» или «кв. slug» — квест площадки (`https://metravel.by/quests/<city_id>/<slug>`). Видео: «есть: <папка>» — исходники найдены в архиве по названию места (инвентаризация, выборочная проверка); «проверить» — статья 2022+ без найденной папки, архив искать при подготовке пакета, нет клипов — карусель; «нет» — исходников нет (статья до 2022); «—» — карусель, фото из галереи статьи или обложка квеста; «нужно снять» — материала нет, раздел 3. Пометка: «новое» — не было в Instagram; «повтор: новый формат» — тема или статья была, подача новая; «повтор внутри плана» — один материал в двух слотах плана, выбрать один при pack; «нужно отснять» — слот держится на съёмке; «новая поездка 2027» — слот под свежую поездку недели (статью по ней при необходимости пишет `travel-writer` по запросу владельца); «утверждено» — владелец уже одобрила, «в расписании IG» — стоит в расписании Instagram.

**Факты в хуках.** Числа в хуках — только из заголовков статей, из уже записанных в `docs/INSTAGRAM_PLAN.md` фраз (они сняты с текста статей) и из данных квестов (`points`, `duration_min`). Где числа нет, хук без числа; перед публикацией каждая единица проходит `pack`: проверка автора (`userIds == "1"`, `publish`, `moderation` — для всех 81 белорусской статьи проверено по API 06.10.2026, для остальных — по выгрузке инвентаризации 06.10), сверка факта по тексту статьи, сверка дат событий. Хуки Mar–Oct 2027 не расписаны: только тема, повод и источники.
