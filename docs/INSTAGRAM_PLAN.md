Старт: 05.10.2026. Горизонт: 4 недели, 06.10–02.11.2026. Модель работы с 05.10.2026 (решение
владельца): агент готовит всё — тексты, слайды, сценарии роликов, подбор исходников на дисках,

## Цель и аудитория (решение владельца 05.10.2026)

Наращиваем русскоязычную аудиторию, которая живёт в Польше: русскоязычные белорусы, украинцы и
россияне в Польше. Сейчас подписчики — по странам: Беларусь 5 143 из 7 098 (72%), Польша 613
(8,6%), Россия 450, Украина 217; по городам Польши — Варшава 178. Контент аккаунта и так
польский (из 334 опубликованных статей автора 1 в 162 в поле «страна» есть Польша: 152
только Польша, 5 «Польша, Словакия», остальные — маршруты через несколько стран; снято
05.10.2026 по API), но в последних роликах это не использовалось: хуки были про Люксембург,
Нормандию, Италию.

Что из этого следует для контента:

- Не менее 80% единиц календаря — про Польшу и для тех, кто живёт в Польше: «куда поехать на
  выходные из Кракова / Варшавы / Вроцлава / Катовице», «маршрут на один день», «сколько
  стоит», «как доехать без машины», сезон (октябрь–ноябрь). Непольская тема — не больше одной
  в неделю и только в доказанном формате (обзор маршрута целиком с цифрами). GR21 в неделе 1
  — это одна тема в двух форматах (ролик и карусель).
- Каждая единица самодостаточна, хук — польза плюс число из статьи. Первая строка подписи —
  место, страна и польза («Куда поехать из Кракова на день: …»): по этим словам аккаунт ищут.
- В подписи — слова, по которым ищут в Instagram: «Польша», город («Краков», «Катовице»),
  «выходные», «маршрут», название места; геометка места ставится при публикации (в каждом
  блоке — название точки); хештегов 3–5, среди них польское гео (#польша #краков #татры
  #силезия и т. п.) и один брендовый (#metravel).
- Число подписчиков из Польши у аудитории, не связанной с Беларусью, растёт только через
  охват неподписчиков: это Reels и карусели с сохранениями. Поэтому метрики цели ниже —
  сохранения и репосты на единицу, а не только просмотры.

## Ритм

- Reels: вторник, четверг, суббота. Карусели: среда и воскресенье (с 06.10.2026, решение
  владельца; две в неделю, их готовит агент). Истории: каждый день, 3–5 штук, минимум одна

- Время публикации — 18:00 по Варшаве, за час до пика 19–21. Ночью и днём не публикуем.
- Не больше одной единицы в сутки; пауз и залпов нет: лучше пропустить день, чем выложить две.
- Ответ на каждый комментарий и сообщение — в первый час после публикации (владелец).
- Каждая единица: польза в хуке, число из статьи, один призыв, конкретный вопрос в конце,
  геометка места, 3–5 хештегов с польским гео.
- Чистка: ведёт агент, до 5 удалений в сутки до 11.10.2026, дальше до 10 (см. «Чистка подписчиков»).

## Производство роликов

- Нужны ли Reels: да. За 30 дней до 04.10.2026 Reels дали 99% просмотров, и только они
  доходят до неподписчиков. Карусели — среда и воскресенье, для сохранений и репостов.
- Автосборка отклонена владельцем (05.10.2026): ролики из `scripts/instagram/make-reel.py`
  (GR21, Тропа ведьм, Tre Cime) ей не понравились и не публикуются. Файлы в
  `.codex-temp/instagram/reels/` в публикацию не идут.
- Reels на темы, которые в аккаунте уже были, = пробные перезаливы готовых роликов владельца
  (очередь — раздел «Очередь пробных перезаливов»). Исходник — оригинал без водяного знака Instagram: файл из галереи телефона
  или из архива (не скачанный из Instagram). При публикации включить «Пробный период», а
  автопередачу подписчикам выключить: подписчики эти ролики уже видели. Через 24–72 часа
  открыть статистику ролика в приложении, записать просмотры и долю досмотров в таблицу очереди.
- Новые Reels (обычные): агент пишет сценарий (хук, текст по секундам, кадры с путями к клипам,
  подпись) и монтирует из живых клипов; черновик показывается владельцу до публикации, она утверждает. Карусели и тексты делает агент; карусель
  собирается скриптом `make-carousel.py` из своих фото и фактов статьи автора 1.
- Пробные Reels (решение владельца 04.10.2026, уточнено 05.10.2026): ролики на темы, которые в
  аккаунте уже были, публикуем как «Пробный период» — их видят только неподписчики.
  Автопередачу подписчикам для перезаливов не включаем. Обычным роликом выходят только новые
  темы (например, Mullerthal после публикации статьи). Подписчиков в это время держат истории
  и воскресная карусель. Ролики-главы («День N» по Тропе ведьм и GR21, переезды по Италии)
  не перезаливаем: без контекста дневника они непонятны.
- Публикация (решение владельца 05.10.2026): карусели и фото-посты агент готовит и публикует сам
  через Graph API, но только после явного «да» владельца на конкретную публикацию в чате;
  одно «да» — одна публикация, на следующую оно не переносится. Reels: агент готовит хук,
  текст по секундам, список клипов из архива и подпись; публикует после «да» тоже через API,
  пробные — с `--trial manual` («Пробный период», ролик видят только неподписчики). Истории
  со стикерами остаются на владельце: API стикеры не умеет.
- Публикация через API подключена и отрепетирована 05.10.2026. Скрипт
  `scripts/instagram-post.js` (`--carousel <папка>`, `--image <файл>`, `--reel <файл.mp4>
  [--trial manual]`, всегда `--caption-file`). Без `--publish-approved` — репетиция: медиа
  загружается, Instagram создаёт контейнер, в аккаунте ничего не появляется (так прошли

  галерею служебного неопубликованного черновика на сайте (id 786), видео отправляет в Meta
  напрямую. У токена есть `instagram_content_publish`. `scripts/instagram-publish.js` — другой
  скрипт (встройки постов в статьи), в Instagram он ничего не публикует.
- Качество исходника Reels: через API Instagram отдаёт свои ролики 2026 года в 720×1280, а
  старые хуже (Костелиска 2024 — 360×640). Для перезалива старых роликов нужен оригинальный
  файл с диска или телефона; 360p в публикацию не идёт без согласия владельца.
- Источник роликов: исходники из архива владельца (диски `/Volumes/T7` и `/Volumes/4tbJuli`,
  только чтение; список папок по каждой единице — в календаре). Папки `T7/video` — DJI-клипы без

  в Reels не берём. Папки ДО 2022 года на дисках нет: для статей 2021 года (замки Юры и др.)
  исходник — фото галереи статьи.
- Карусель: `python3 scripts/instagram/make-carousel.py <spec.json>` (слайды 1080×1350). Поля
