Дата плана: 26.10.2026. Реализация начата 27.10.2026 с поезда A (#2791–2794).
Готовые книги и публичный раздел ещё не выпущены.
Борд: [активный спринт #30](https://metravel.by/board?sprint=30), родительская
feature-карточка релиза #2786, release-id `travel-books-v1`.
Источник: прямой запрос владельца. Спецификация: `openspec/changes/add-travel-memory-books/`.
Нормативный дизайн: `docs/design/travel-memory-books-v1.md`.

## Feature Brief

Problem: человеку приходится самому искать места, верстать альбом и выяснять, как его напечатать. Экспорт уже написанных статей — другой сценарий.

Audience: русскоязычные самостоятельные путешественники, пары и семьи, которые ездят по Беларуси и Польше и хотят сохранить бумажные воспоминания.

User stories:

- Выбрать готовую книгу по стране, пролистать её целиком, понять размер фото и скачать без регистрации.
- До поездки прочитать о месте и найти его по координатам/QR, после — вклеить фото, билет или открытку и записать впечатления.
- Напечатать дома по понятной инструкции либо выбрать город и получить подходящие сведения о типографии.
- Распечатать наклейки, отмечать посещённые места и постепенно собрать собственную книгу.

Platforms: desktop web | mobile web. Нативный редактор, share/save API и store release не входят в v1.
Locales: UI RU/BE/UK/PL/EN; контент книг только RU. Язык книги виден до скачивания. RU+BE/RU+PL — возможные будущие редакционные издания, не автоматическое смешение языков.

Acceptance criteria: две законченные книги, два физических формата каждой, совпадающие предпросмотр и PDF, проверенные материалы и права, полный домашний комплект, инструкции, наклейки, каталог печати, подтверждённая производственная приёмка.

Non-goals: оплата, paywall, реальная отправка заказов, редактор фотографий/маршрутов, произвольные размеры, обязательная регистрация, автоматический перевод, выпуск всех тематических серий одновременно.

Content/data assumptions: стартовый отбор — 12 мест на страну; издания описывают несколько самостоятельных поездок, а не обещают один непрерывный автомобильный маршрут. Изображения сайта используются только с достаточными правами и разрешением для печати.

Metrics: просмотр каталога → открытие книги → предпросмотр → выбор формата → успешное начало скачивания; отдельно открытие инструкции и переход к провайдеру. Не считать клик заказом, а скачивание — физически напечатанной книгой. Первые 30 дней формируют baseline; числовые цели задаются после измерения, не выдумываются.

Risks: размер фотографии, корешковые поля, толщина вклеек, порядок оборотов, кириллица, права на фото, устаревающие условия посещения и печати, отличие PDF для дома и типографии. Производственный образец закрывает то, чего не докажет экран.

Open questions: окончательный партнёр для прямой отправки, коммерческие условия и цена. Они вынесены в последующий этап и не блокируют бесплатное скачивание v1.

## Состав первого релиза

### Готовность данных (A1)

Редакционный снимок `EditorialBookDraft` (`status: editorial-draft`) хранится в
`data/travelBooks/{by,pl}/editorial.json`. Он содержит 12 мест, локальные названия,
русские тексты, наблюдения, источники с датами, координаты с указанием точности,
группы самостоятельных поездок и задания для иллюстратора. `gaps` перечисляет
неподтверждённые сведения; структурно корректный черновик с такими пробелами
не считается принятым редакционным материалом. Отсутствие изображений и PDF
не заменяется фиктивными адресами или контрольными суммами.

`ReadyBook` (`status: ready`) проверяется отдельно: обязательны права на печать,
изображения, оба физических профиля, полный комплект файлов и предпросмотр.
`source.kind: official` обозначает реальный официальный источник; внутренние
`place|travel-address|quest-step` сохраняются для снимков из каталога MeTravel.
`coordinateAccuracy` различает точный вход, ориентир подхода и центр объекта;
`coordinateSource` позволяет независимо проверить эту геометрию. Центр объекта
не выдаётся за точную дверь. Легенда — отдельный объект с подписью «Легенда»
и источником. Неизвестный набор высоты природного маршрута хранится как `null`
только в черновике вместе с явным пробелом; готовая книга требует проверенное число.

Предпросмотр разделён на `body` (56 страниц) и `cover` (4 стороны), отдельно для
каждого профиля. `sourceSha256` связывает его с точным PDF назначения `read` того
же компонента. Все 56 внутренних номеров сохраняются независимо от обложки.
Для обложки существуют отдельные `read`, `home-rings` и `print-shop` файлы;
`home-sewn` A5 использует отдельную домашнюю обложку из `home-rings`.
Верификация хешей/размеров не доказывает, что картинка действительно является
страницей соответствующего PDF: сравнение и предпечатный контроль выполняются B4/C1.

Команды:

```sh
node scripts/validate-ready-books.mjs --editorial
node scripts/validate-ready-books.mjs --metadata-only path/to/manifest.json
node scripts/validate-ready-books.mjs --assets-root path/to/public-root path/to/manifest.json
```

Первая проверяет редакционные данные обеих стран. Вторая проверяет только
структуру manifest и явно не подтверждает наличие файлов. Третья дополнительно
проверяет реальные локальные файлы, их размер и SHA-256, с защитой от выхода за
корень пакета. По умолчанию публикационная проверка требует оба manifest и
`--assets-root`; отсутствующий комплект завершается ошибкой. PDF-шрифты,
ppi, переполнение и бумажный пробник остаются отдельными производственными проверками.

### Издания

| Издание | Содержание | Форматы | Результат |
| --- | --- | --- | --- |
| Беларусь. Замки, города и природа | 12 мест, обзорная карта, мини-поездки, факты, память | 150×100 мм; A5 148×210 мм | Полный русский комплект |
| Польша. Замки, города и горы | 12 мест, обзорная карта, мини-поездки, факты, память | 150×100 мм; A5 148×210 мм | Полный русский комплект |

Каждое издание: 56 внутренних страниц + отдельная обложка из четырёх сторон. Первые пять страниц — титул, подготовка, использование дневника, содержание, обзорная карта. Страницы 6–53 — 12 блоков по четыре страницы. Страницы 54–56 — дополнительные воспоминания, итоговый список, выходные данные/источники. Страница 6 и каждый следующий старт блока — чётная, левая; справа страница памяти. Обложка не должна сдвигать эту пагинацию.

Два профиля не означают два разных текста. Контрольный manifest фиксирует редакцию, состав, порядок и все артефакты. На каждом файле видны страна, язык, формат, назначение и версия.

Это кандидаты для исследования, не проверенный путеводитель и не утверждение о доступности объекта сейчас. В задачах редактора обязательны официальные источники, координаты, актуальность доступа и самостоятельная проверка каждого факта.

Критерии отбора: выразительный объект, разнообразие, доступный легальный подход, достоверная история, качественное изображение с правами, возможность самостоятельной поездки. Для гор — набор высоты, время и сложность по официальным материалам, сезонность, закрытия и ссылка на текущие предупреждения парка. Не обещать «подходит всем»; небезопасный или неподтверждённый маршрут заменить.

На место: координаты, локальное название для поиска, ориентир входа, 350–550 знаков истории для compact и расширение до 900 знаков A5, один проверенный факт, легенда только с явной пометкой, маленькое наблюдательное задание без опасных действий, поля даты/компании/впечатлений. Не публиковать быстро устаревающие цены и часы как бессрочные факты: QR ведёт на официальный источник или страницу MeTravel со ссылкой на него.

## Дизайн и материалы

Общая серия — светлый бумажный фон, выразительное изображение, спокойные акценты, крупные читаемые подписи, место для рукописного заполнения. Беларусь — природно-зелёный акцент; Польша — тёплый терракотовый. Для приложения используются текущие tokens; печатная палитра хранится отдельно и проверяется в RGB/реальном профиле провайдера.

Слева изображение и история, справа фотография; ещё один разворот посвящён записям и дополнительным вклейкам. A5 принимает обычную фотографию 10×15; compact — минифото до 70×100 мм. Горизонтальный снимок 10×15 на вертикальной A5 требует поворота или отдельного вкладыша. Толстые открытки не должны перекрывать корешок.

Иллюстрации: узнаваемое конкретное место; фото сайта с разрешением либо авторская/AI-иллюстрация с пометкой. Иллюстрация не служит доказательством современного состояния здания. Запрещены выдуманные башни/детали, подмена города, коммерческое использование чужого фото без прав. Реестр фиксирует автора, источник, лицензию/разрешение, изменения и разрешение печати.

## Пользовательский путь и раздел сайта

1. Общая навигация → «Книги путешественника». На мобильном — существующее «Ещё», без дополнительного пункта нижнего дока.
2. `/books`: короткое объяснение, две готовые книги, страна/язык/число мест/физический размер, ссылка на инструкцию. Будущие серии не выглядят как уже доступные.
3. `/books/[slug]`: обложка, для кого книга, содержание и места, полный предпросмотр, размеры фото, выбор compact/A5, состав файлов, домашняя печать/типография/наклейки.
4. Предпросмотр показывает фактическую редакцию: на телефоне одиночная страница, на desktop разворот; текстовое содержание и переход по странице доступны клавиатурой.
5. Скачивание готового файла: без входа, без серверного рендера по нажатию. Показываются формат, число страниц и размер файла. Повторная попытка при ошибке.
6. «Напечатать дома» — выбрать способ, скачать точный пакет, выполнить контрольный лист. «В типографии» — страна/город, подтверждённые возможности и тираж, пакет и переход на сайт поставщика.
7. Ссылки из подходящих квестов/точек/статей — по совпадению страны/места, без массового изменения опубликованных текстов.

На ширине 320–390 px нет горизонтальной прокрутки интерфейса; само масштабируемое полотно предпросмотра может иметь управляемое перемещение. Touch-target не меньше 44 px, контраст и focus; состояние ошибки не маскируется пустой обложкой. Нет автоматической передачи фото, адреса, телефона или e-mail стороннему провайдеру.

## Комплект скачивания

- `read.pdf`: страницы по порядку, без производственных меток; основа полного предпросмотра.
- `home-a4-cut.pdf`: готовая раскладка, контрольный лист, линии реза, сборка на кольца; для compact две страницы одна над другой, а не разворот шириной 300 мм.
- `home-a4-sew.pdf`: только A5, проверенные тетради 16+16+16+8 внутренних страниц с маркировкой; контроль сгиба и прошивки. Не включать этот файл в compact как будто он помещается на A4.
- `print-shop.pdf` и `cover.pdf`: отдельные последовательные страницы в физическом размере. Общий RGB-файл помечен как требующий согласования; конкретный профиль провайдера получает отдельный файл и паспорт проверки.
- `stickers-a4.pdf`: два листа на страну: 12 марок мест и отметки/даты/эмоции. Универсальная ручная резка; шаблоны готовых этикеток — только с точным артикулом.
- `instructions-ru.pdf`: выбор файла, бумаги, принтера, тест, печать, сборка, вклейка, QR, типографии; дополнительно краткая польская записка о заказе готового RU PDF.
- `print-passport.pdf`: размеры, обрез, вылеты/поля, страницы, переплёт, цветовой профиль, версия, контактный сайт, дата проверки требований, контрольные суммы в manifest.

Пакет доступен отдельными файлами; ZIP — удобное дополнение. Не заставлять скачивать все PDF ради инструкции. Весь PDF самодостаточен: картинки, карты, QR и кириллические шрифты встроены. Ссылки помогают найти актуальные данные, но их доступность не нужна для отображения PDF офлайн.

## Инструкция домашней печати: обязательный состав

1. Отличить размер книги от размера фотографии и листа принтера. A6 105×148 — другой формат, чем 100×150.
2. Распечатать контрольную линейку 50 мм и схему лицевой/оборотной стороны на обычной бумаге. Измерить линейкой; допуск ±1 мм. При отклонении исправить масштаб до основного тиража.
3. Готовый A4-файл: «Фактический размер/100%», одна PDF-страница на лист. Выключить повторное «Брошюра», «Подогнать» и «Несколько страниц на листе».
4. Автоматический дуплекс — выбор края по конкретному контрольному листу; ручной — тест направления повторной подачи и порядок страниц, а не универсальное обещание «перевернуть так» для всех моделей.
5. Для compact: A4 portrait, две страницы 150×100, резка и отверстия. Сгибной разворот 300×100 не помещается в 297 мм. При желании исходный размер через сгиб требует A3/другого отдельного профиля.
6. Для A5: A4 landscape, белые непечатаемые края учтены. Готовая раскладка под кольца либо отдельные пронумерованные тетради под прошивку; без повторной перестановки страниц драйвером. Для точного A5 обрезать 0,5 мм по внешнему краю после сгиба либо предварительно укоротить длинную сторону A4 с 297 до 296 мм.
7. Ориентир бумаги: немелованная 120–160 г/м² для записей, обложка 250–300 г/м². Проверить предел конкретного принтера, особенно автодуплекса; меньшая допустимая плотность приоритетнее рекомендации. Сначала проверить письмо ручкой/карандашом и отпечаток с двух сторон.
8. Обрезка, порядок страниц, безопасные отверстия и запас колец под будущие вклейки. Самоклеящиеся уголки/материалы для фотографий; тест чернил и клея на обрезке. Для прошивки только ограниченное число тонких вклеек, рекомендуемый основной альбомный переплёт — кольца/пружина.
9. Наклейки: подходящая конкретному лазерному/струйному принтеру самоклеящаяся A4; тест на простой бумаге 100%, потом печать и ручная резка. Не отправлять неподходящую плёнку в лазерный принтер.
10. Проверить бумажный пробник: измерение, читаемость, последовательность, QR, реальные фото/открытка, раскрытие и добавленная толщина.

Польша — Warszawa, Kraków, Łódź, Wrocław, Poznań, Gdańsk, Szczecin, Bydgoszcz, Toruń, Lublin, Białystok, Kielce, Olsztyn, Rzeszów, Opole, Katowice, Gorzów Wielkopolski, Zielona Góra. 18 городов учитывают два административных центра в двух воеводствах.

Для каждого города результат либо подтверждённый местный пункт, либо «доставка из другого города», либо честное «подходящий вариант пока не подтверждён». Национальную доставку нельзя изображать филиалом. Тиражный провайдер не удовлетворяет фильтру «1 экземпляр».

Отдельные поля: `acceptsRuPdf: yes|no|unknown`, `contactLanguages`, `deliveryCoverage`, `minimumCopies`, `supportedProfiles`, `checkedAt`, `sourceUrls`, `verification: published|sample-confirmed`. Внедрённый кириллический шрифт технически помогает печати, но не доказывает обслуживание на русском. Несовместимый профиль нельзя отправлять кнопкой «готов к заказу».

Общий print-shop профиль: исходно 3 мм вылетов, safe 5 мм и внутреннее поле 15 мм; это исходный макет, а не универсальное требование. У конкретного провайдера возможны 2 мм и другие поля. RGB/CMYK и PDF/X подтверждаются фактической проверкой и при необходимости допечатной подготовкой. Chromium сам по себе не гарантирует CMYK/PDF-X.

## Зависимости и приёмка

A1/A2 → B2; A3/A4 → B1; A3/A4/B1/B2 → B4; B2 → B3; B3/B4 → C1; A1/A2 → C2; C1/C2 → C3; C2 → C4; D1 может исследоваться параллельно A; A3/A4/B1 → D2; B3/D1/D2 → D3; C1/D2/D3 → H1; C2/C3/C4/D1/D2/D3/H1 → D4. Жёсткие зависимости записываются реальными id на борде, смежные старые задачи остаются related.

Приёмка v1:

- 2 страны × 2 физических формата: полные 56 страниц и обложки, 12 точек, редакционные источники/права, правильные левые/правые развороты.
- `pdfinfo`/геометрия, `pdffonts`/внедрённая кириллица, `pdftotext`/русские подписи, `pdftoppm`/визуальные листы; соответствие manifest, отсутствие внешних ресурсов для отображения; контроль эффективного ppi.
- Содержимое предпросмотра и PDF совпадает по версии, порядку и числу страниц. Ошибки/повтор доступны, сайт не делает PDF-render на каждый просмотр.
- Контрольный домашний лист 50 мм, обе стороны, правильный рез/сгиб, читаемый QR, место под реальные фото 100×150/102×152 на A5; mini-photo и запас колец на compact.
- Покрытие 6+18 городов с честными неизвестными полями; не обещать приемлемый тираж, доставку, RU обслуживание или производственную готовность без evidence.
- Для отметки «готово для типографии» нужен хотя бы один подтверждённый провайдерский профиль на каждую страну и каждый формат: приём точного файла и тиража, поля/цвет/переплёт. Если подтверждения нет, выпуск полного v1 не принят; готовый домашний комплект можно показать только как явно обозначенный частичный выпуск.
- Code-only review → commit/push → testing → production deploy → browser приёмка mobile web, затем desktop, console/network, реальное скачивание файлов с production и сверка SHA. Нативные прогоны/полный e2e не добавляются без отдельного изменённого контракта.
- Исторические экспорты A4 и квестовая печать сохраняют smoke/regression evidence.

Команды при реализации выбираются по изменениям: `npm run test:i18n`, `npm run guard:external-links`, targeted Jest геометрии/manifest, существующие PDF governance/golden проверки. Валидатор `node scripts/validate-ready-books.mjs` реализован A1; его редакционный режим и проверка реальных файлов описаны выше. `scripts/build-ready-books.mjs --check` и UI-сценарии `e2e/ready-books.spec.ts` запланированы в производственном/пользовательском этапах и пока не реализованы. Browser QA запускается после review в `testing`.
