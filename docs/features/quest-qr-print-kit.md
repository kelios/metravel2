# QR-комплект квеста для печати

Карточка #3248. Локальный генератор создаёт листовку A5 (148×210мм), наклейку100×120мм и manifest одного опубликованного квеста. Нормативный макет: [quest-qr-print-kit.md](../design/quest-qr-print-kit.md). Это файлы для подготовки пилота #3250; печать и размещение выполняются отдельно.

## Одна команда

Из корня frontend-репозитория после установки зависимостей из yarn.lock:

```bash
node scripts/quests/build-qr-kit.mjs --quest-id minsk-cmok --campaign park-start-01 --locale ru
```

`--quest-id` принимает публичный quest_id либо числовой id. `--campaign` обязателен: короткий код площадки из1–64 строчных латинских букв, цифр, `_` и `-`, первый знак — буква/цифра. Используйте код площадки без персональных данных. `--locale` — ru (по умолчанию), be, uk, pl или en. Выход по умолчанию — `.codex-temp/quest-qr-kit/<id>-<locale>-<campaign>`; можно указать свежую директорию через `--output`. Существующие файлы и директории не заменяются.

Для PDF нужен Python3 с ReportLab. Если `python3` не содержит пакет, используйте своё окружение:

```bash
python3 -m venv .codex-temp/quest-qr-venv
.codex-temp/quest-qr-venv/bin/pip install reportlab
node scripts/quests/build-qr-kit.mjs --quest-id 4 --campaign park-start-01 --locale be --python .codex-temp/quest-qr-venv/bin/python
```

Также поддерживается `QUEST_QR_PYTHON`. Лицензированные Noto Sans Regular/Bold и палитра берутся из существующей печатной системы. QR создаётся локально, внешнего QR-сервиса нет.

## Данные и язык

Генератор читает только анонимные опубликованные `web/discovery` и `web/detail` через существующие строгие validators. Игровой bundle, который увеличивает views_count, не запрашивается. По умолчанию источник — `https://metravel.by`; для подготовленного локального publisher доступен `--api-origin http://localhost:8000`. Неподготовленный локальный publisher может отдавать503; обычного runserver для его запуска недостаточно.

Исходный заголовок, длительность и is_free берутся из опубликованной projection. Клиент не переводит контент квеста. Подписи бумаги локализованы через @/i18n на RU/BE/UK/PL/EN. Если выбранный перевод не опубликован (404), используется реальный RU-источник, оба языка записываются в manifest. Сбой503 и неверная схема не подменяются успешным RU-ответом. Неизвестная длительность прямо отмечается; is_free=false не печатает обещание бесплатности. Опубликованный noindex-квест допустим.

## Ссылки и аналитика

QR и clickable link в PDF ведут на один канонический опубликованный адрес:

```text
https://metravel.by/quests/4/minsk-cmok?utm_source=qr&utm_medium=referral&utm_campaign=park-start-01
```

Для опубликованного перевода используется его канонический путь. `referral` взят из стандартных medium в utils/utm.ts. Начальный GA page_location сохраняет query; стандартные GA source/campaign задают источник qr и площадку. Существующий собственный traffic_source остаётся campaign. Новых событий и искусственных стартов генератор не создаёт. Реальные старты с согласившихся посетителей измеряются на пилоте; отсутствие таких переходов не является численным нулём эффективности.

## Приёмка результата

Manifest содержит идентификатор публикации/ревизию и хеш источника, точный текст, языки, campaign, targetUrl, размеры и хеши PDF, размеры модуля QR и фактический кегль заголовка. Каждый PDF — одна страница. Минимальный модуль QR0,4мм и тихая зона4модуля; заголовок не обрезается, переполнение останавливает генерацию. Печать —100%, без подгонки под лист.

Для двух реальных квестов сверяются страничные размеры, встраивание шрифтов, весь напечатанный текст и PDF link. Каждая точная PDF-страница растрируется в300dpi; цветной и серый варианты должны декодироваться ровно в targetUrl. Отдельно смотрятся страницы, чтобы обнаружить наложения и пустые глифы. Целевые Jest и text snapshots используют сохранённые реальные ответы API с provenance; они не заменяют приёмку новых итоговых PDF.
