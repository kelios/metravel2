# Макет чеклиста снаряжения в планировщике

Статус: норматив для задач чеклиста «есть / купить / взято» в planned trip.
Экран: `/trips/plan/:id` → вкладка «Ещё» (после отчёта и рейтинга) и компактный блок
в форме создания, если поездка уже сохранена.
Связанные контракты: `docs/features/trips.md`, `docs/DESIGN_SYSTEM.md`.

Норматив: владелец отмечает каждую вещь одним из трёх статусов. Участник видит
тот же список только для чтения. Гость списка не видит.

## Desktop web — владелец, есть вещи

```text
Ещё
────────────────────────────────────────────────────────────
Снаряжение                         8 из 14 готово     [Шаблон]
Документы
  [взято] Паспорт / ID
  [есть ] Страховка
  [купить] Luxembourg Card (не нужна: транспорт бесплатный)
Одежда и обувь
  [есть ] Треккинговые ботинки
  [купить] Непромокаемая куртка
  [взято] Флиска
  [     ] + добавить вещь
```

Статусы в этом порядке: `купить` → `есть` → `взято`. Тап по чипу циклически
переключает статус и сразу сохраняет. Подпись чипа не короче 44×44 px.

## Mobile web — владелец, пустой список

```text
Снаряжение
Пока пусто. Добавьте вещи или возьмите шаблон
для пешего маршрута.

[Шаблон для хайкинга]   [Добавить вещь]
```

## Состояния

| Состояние | Что видно |
| --- | --- |
| empty | текст пустого списка, две кнопки: шаблон и ручное добавление |
| loading | скелетон 3 строк, без скачка высоты относительно 3 вещей |
| error | инлайн-ошибка и «Повторить»; список не пропадает, если уже был |
| readonly | чипы статусов не нажимаются, кнопок шаблона и удаления нет |
| packed-complete | в шапке «все вещи взяты», без конфетти и без отдельного экрана |

## Не входит в макет

Фильтры по магазинам, цены, партнёрские ссылки на конкретный товар, шаринг
чеклиста отдельной ссылкой, печать PDF. Это отдельные задачи.
