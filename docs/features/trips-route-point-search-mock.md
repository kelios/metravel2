# Поиск места в форме точки маршрута

Норматив для #1782, 2026-09-06. Экран: `/trips/plan/:id` → точки маршрута.
Источник поведения — Task Contract #1782. Компоненты: `RouteBuilder`,
`RoutePointAddForm`, существующий `AddressSearch`.

## Добавление

```text
Добавить точку
[ Найти место по названию или адресу      × ]
  Острава, Моравскосилезский край, Чехия

[Место] [Своя точка] [Отдых] [Ночёвка]
[Название точки                            ]
[Широта              ] [Долгота             ]
[Описание                                  ]
[Добавить точку] [Отмена]
```

Выбор результата заполняет координаты в открытой форме. Пустое название
получает короткое имя места. Уже введённые название и описание сохраняются.
Пользователь может исправить поля до нажатия «Добавить точку»; выбор подсказки
сам по себе не добавляет точку и не сохраняет маршрут. Отмена не меняет маршрут.

Если выбран режим «Место», результат внешнего геокодера переключает форму
на «Своя точка»: у результата нет `placeId` MeTravel. Поля, скрытые в режиме
«Место», не переносятся из предыдущей попытки. При выборе остальных типов
категория сохраняется. Поиск по каталогу MeTravel сохраняет отдельное поведение.

## Редактирование

```text
[Своя точка] [Отдых] [Ночёвка]
[ Найти место по названию или адресу      × ]
[Название точки                            ]
[Широта              ] [Долгота             ]
[Описание                                  ]
[Сохранить] [Отмена]
```

Выбор результата меняет оба поля координат; непустое имя пользователя остаётся.
Пустое имя предзаполняется. Изменение становится частью черновика маршрута
только по действию сохранения точки. Переход к другой точке сбрасывает поиск.

## Состояния и проверяемые поверхности

- До трёх символов — существующая подсказка минимальной длины; при запросе —
  индикатор. Результаты, пустой ответ и ошибка используют существующий UI
  `AddressSearch`; ошибка допускает повтор и не блокирует ручные поля.
- Выбор языка RU/BE/UK/PL/EN меняет подписи, язык геокодера и ключ кэша.
  Название из ответа геокодера не переводится на клиенте.
- Desktop web 1280×900: форма в панели маршрута, список подсказок в её ширине.
  Mobile web 390×844: те же действия в мобильной раскладке, без горизонтального
  переполнения; координаты и кнопки доступны при открытой клавиатуре.
- iOS simulator и Android device: клавиатура позволяет выбрать подсказку,
  прокрутить форму, вручную изменить координаты и подтвердить точку.
- Проверить добавление, отмену, редактирование и повторное открытие сохранённого
  маршрута. Координаты Остравы должны попасть в точку в порядке `[lng, lat]`.
  Моки допускаются только в unit-тестах; runtime использует реальный поиск.

Вёрстка использует существующие стили и компоненты. Этот документ задаёт
поведение и состояния, а не подтверждает прохождение браузерной/device QA.
