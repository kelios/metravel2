## Два размещения

Новая продуктовая граница: compact-phone (<600 CSS px, мобильная строка экрана), высота без клавиатуры <840 CSS px. Ниже показана геометрическая оценка для состояния без pending/photo. Реальные first/pinned markers и пределы .155/.197 не меняются.

```text
320×640 — короткое окно            390×844 — обычное окно
┌───────────────────────────┐     ┌───────────────────────────┐
│ ← Название       (i)   ⋯  │54   │ ← Название       (i)   ⋯  │54
├───────────────────────────┤     ├───────────────────────────┤
│ Маршрут ▾ │ Язык: русский │44   │ Маршрут ▾ │ Язык: русский │52*
│ ┌───────────────────────┐ │     ├───────────────────────────┤
│ │ Задание / интро       │ │98   │ ┌───────────────────────┐ │122*
│ │ Текст, ответ, действия│ │     │ │ Задание / интро       │ │
│ └───────────────────────┘ │     │ │ Текст, ответ, действия│ │
│ маршрут и задание ↑↓      │     │ └───────────────────────┘ │
├───────────────────────────┤     ├───────────────────────────┤
│ существующий док          │56   │ существующий док          │56
└───────────────────────────┘     └───────────────────────────┘
```

В коротком окне только глобальная строка и док закреплены. Маршрут — первый элемент прокрутки, видимый на входе и после перехода точки. На обычном экране маршрут сохраняется над прокруткой. `52*` и `122*` — прежние измеренные размеры с отступами, не новая высота кнопки: сама строка маршрута остаётся 44 px.

Короткая геометрия оценивается как first=98 px и pinned=110 px. На 640 это .153125/.171875; запас первого бюджета лишь 1.2 px, поэтому расчёт нельзя объявлять PASS. Нижняя высота существующего бюджетного контроля — 640; ниже него все действия остаются достижимыми, без новой гарантии ratios.

## Нормативные состояния

| Состояние | Короткое окно | Обычное окно / desktop |
|---|---|---|
| RU / настоящий перевод | Один маршрут перед заданием, язык не добавляется | Прежнее размещение |
| BE/UK/PL/EN → RU | Полный язык отдельным пассивным соседом кнопки, без вложенного нажатия | Прежний полный язык / размещение |
| После прокрутки | Ряд ушёл вверх вместе с заданием; прокрутка к началу возвращает его | Маршрут остаётся закреплённым |
| Pending / фото | Отдельный видимый статус перед маршрутом в той же прокрутке, прежнее действие | Прежний семантический ряд |
| Открытый лист | Все точки, текущая строка и закрытие доступны; resize не закрывает лист | Прежнее действие |
| Ввод / клавиатура | Видны поле и feedback; режим не переключается до завершения ввода | Прежнее раскрытие поля |
| Офлайн-копия | Язык копии, offline и pending явно видимы, доступен маршрут | Прежнее состояние |
| Финал / согласие | Существующие действия и согласие; маршрут, где он существует, подчиняется той же политике | Прежний completion-контракт |

Шрифты, иконки Feather, цвета, горизонтальные 16 px и внутренние отступы карточки сохраняются. Не допускаются скрытый язык, обрезка счётчиков, уменьшение 44 px целей, второй ряд закреплённых действий или изменение глобального заголовка.

## Смена размера

Режим считается из размера layout-окна, не из высоты visual keyboard viewport. При активном листе, фокусе ввода, клавиатуре или прокрутке решение откладывается. После завершения взаимодействия новое размещение применяется с компенсацией scroll anchor; один ScrollView, его ref и поддерево задания сохраняются. Только смена точки штатно возвращает начало. Проверяются обе стороны 839↔840, 640↔844 и переход ширины 599↔600.
