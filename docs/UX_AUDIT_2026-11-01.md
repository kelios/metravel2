# UX-аудит metravel.by и приложения — 2026-11-01

Цель: пройти продукт глазами нового пользователя, сопоставить с аналитикой и
завести на борд задачи, которые реально мешают пользоваться продуктом.

Источники и окна измерения:

- прод `https://metravel.by`, встроенный браузер desktop-пейн 800px и эмуляция
  375×812 (Android Chrome UA); сценарии: главная → поиск → статья → «Добавить в
  план» → логин/регистрация; карта; квесты (каталог, квест, сценарий); «Стать
  автором»; `/app`; профиль и «Хочу поехать» без входа;
- Lighthouse mobile по проду: `node scripts/lighthouse-produrl.js --formFactor
  mobile` для `/` и `/travels/grodno-za-1-den-chto-posmotret-i-kak-doekhat`
  (отчёты в `.codex-temp/ux-audit/`, прогон 01.11.2026 ~12:20);
- iOS: симулятор iPhone 17 Pro, локальная Release-сборка `metravel.app` 1.0.5 (9)
  от 09.09.2026 — **сборка старая**, дефекты приложения требуют перепроверки на
  текущем TestFlight;
- аналитика: см. раздел 2 (окна указаны при каждом числе).

## 1. Что видит пользователь — находки прохода

Формат: что сделал → что увидел → почему уходит → где в коде.

### 1.1 Главная

- **H-1. Четыре карточки «За 2 минуты», «Личная книга», «Маршруты рядом»,
  «GPS-треки» выглядят кнопками, но не кликабельны.** Проба в DOM: цепочка
  `DIV < DIV < DIV`, без `role`/`href`/`onPress`. Это первое, на что жмёт новый
  пользователь на desktop; ноль реакции → ощущение «сломано». Источник —
  `HERO_HIGHLIGHTS` в `components/home/homeHeroContent.ts` (без `route`), в
  отличие от `MOOD_CARDS`, у которых маршрут есть.
- **H-2. Чип «Хайкинг» из блока «Куда поехать в эти выходные» ведёт в выдачу,
  где первые карточки — Австрия, Люксембург, Словакия (673–1539 км от Минска).**
  Обещание «в эти выходные» не выполняется: нет сортировки/приоритета по
  расстоянию. `/search?categories=21,22,2`, 123 маршрута.
- H-3. Mobile: карточки «Популярные маршруты» показывают серые полосы сверху и
  снизу фото (contain-слот выше пропорций) — визуально «не догрузилось».

### 1.2 Поиск

- **S-1. Поиск без результатов (`/search?search=qwertyuiop`, а также длинный
  запрос «Лепельский район кемпинг») — бесконечный SSR-скелетон.** Проверено
  ожиданием 8–13 с: 0 карточек, нет сообщения «ничего не найдено», в консоли
  6×`404`. Запросы с результатами (Гродно, Лепель) гидратируются за ~3 с.
  Пользователь с нетипичным запросом считает, что сайт завис. Механизм — ветка
  `activeFallbackMatch / isFallbackLoading / showEmptyState` в
  `components/listTravel/ListTravelBase.tsx:435-565` (empty state есть в коде,
  но на проде не показывается).
- S-2. Релевантность: «Гродно» → после трёх релевантных карточек идут замки
  Польши за 834 км (совпадение по слову «замок»). Счётчик результатов в шапке
  («1») не объясняет, что это число активных фильтров.

### 1.3 Статья маршрута (`/travels/...`)

- **T-1. Нет GPX/GPS-трека и кнопки «открыть в навигаторе».** Hero главной
  обещает «GPS-треки — скачай и следуй маршруту»; на странице маршрута ни одного
  элемента с gpx/gps/трек/навигатор (проба по DOM). Обещание ≠ продукт.
- **T-2. Mobile: первый экран — галерея «1/10» и подпись «01 из 10 Коложская
  церковь», заголовок статьи ниже фолда.** Из поиска пользователь попадает на
  фото без названия — непонятно, туда ли он попал. Заголовок затем дублируется
  (h1 + карточка оглавления с тем же текстом).
- **T-3. «Добавить в план» и «Сохранить офлайн» для гостя → жёсткий редирект на
  `/login?intent=calendar`, ~2 с белый экран, заголовок «С возвращением».**
  Новому человеку говорят «с возвращением», не объясняя, что он получит после
  входа; соц-кнопки серые, пока не отмечен чекбокс согласия. Это главная точка
  потери на пути «гость → аккаунт» (см. 2: регистрация ≈ 2 посетителя/мес).
  Ключ `authScreen.login.title` в `i18n/locales/ru/static/auth_static.ts`.
- T-4. В DOM статьи остаются смонтированные предыдущие экраны (17 кнопок
  «Добавить в план» после перехода из поиска) — лишний DOM (Lighthouse: 1 066
  элементов), шум для скринридеров.

### 1.4 Вход / регистрация / профиль

- **A-1. Соц-кнопки заблокированы до чекбокса согласия** и на `/login`, и на
  `/registration`; подпись «Отметьте согласие, чтобы войти» мелкая. На Android
  UA первичная кнопка — Apple.
- **A-2. `/profile` и `/favorites` без входа — пустой экран «Войдите в аккаунт» с
  одной кнопкой «Войти».** Нет «Создать аккаунт», нет ценности (что даст
  аккаунт). То же в iOS-приложении.
- A-3. `/become-author`: кнопка «Рассказать о поездке» первые ~3–5 с серая
  (`disabled={!authReady}`, `components/author/BecomeAuthorScreen.tsx:60`) при
  подписи «Для создания нужен аккаунт» — выглядит как тупик. Хлебные крошки
  «Become Author» и «More» не локализованы.

### 1.5 Квесты

- **Q-1. `/quests/<несуществующий-slug>` — пустая страница без 404.** Title
  страницы = title главной; `useQuestLandingNotFoundRedirect`
  (`components/quests/QuestLandingLayout.tsx:70`) на web не срабатывает
  (`loading` не завершается). Любая битая ссылка из соцсетей/мессенджеров = белый
  экран.
- **Q-2. Публичный счётчик на `/quests`: «282 квеста · 44 прохождения · 30
  игроков»** — отрицательное социальное доказательство для новичка («никто не
  играет»).
- Q-3. В DOM квеста до старта есть текст «✓ Правильно!» (попадает в текстовую
  выдачу/скринридер).
- Прохождение квеста без логина работает, сценарий для печати понятен — ок.

### 1.6 Карта

- M-1. Web `/map`: 5+ с скелетон до карты на desktop-пейне; затем всё
  работает, баннер геолокации с «Разрешить» уместен.
- **M-2. iOS (сборка 09.09): вкладка «Карта» — тайлы не грузятся (серый фон
  > 60 с), кластеры «4», «11», «1» рисуются ПОВЕРХ тулбара и баннера
  «Геолокация недоступна», маркеры свалены в кучу.** Требует перепроверки на
  актуальной сборке; если воспроизводится — блокер первого впечатления в
  приложении.

## 2. Что говорит аналитика (окно 02–31.10.2026, если не указано иное)

Источники: **[GA4]** `npm run stats:ga4 -- --days 30 --channel-breakdown` и
`--events`, property 362328641; **[GSC]** `npm run stats:gsc -- --days 28`
(02–29.10); **[Снимок]** `.codex-temp/metrics-summary/2026-10-22.md`;
**[QFL]** `docs/QUEST_FRICTION_ANALYSIS_LOG.md`; **[AAL]**
`docs/ARTICLE_ATTENTION_LOG.md`. GA4 видит ~25–30 % органического входа (consent +
adblock): 1 145 кликов GSC против 295 сессий Organic в GA4 — абсолютные цифры
воронок ниже являются нижней границей, соотношения внутри них корректны.

### 2.1 Трафик сжимается

| Месяц | GSC клики | CTR | GA4 users | Сессии | Bounce |
| --- | --- | --- | --- | --- | --- |
| 07.2026 | 2 027 | 2,78 % | 443 | 906 | 31 % |
| 08.2026 | 2 120 | 2,67 % | 416 | 716 | 30 % |
| 09.2026 | 1 491 | 2,67 % | 316 | 483 | 36 % |
| 10.2026 | 1 145 | 2,18 % | 331 | 543 | 40 % |

Август → октябрь: клики −46 %, CTR 2,67 → 2,18 % при той же позиции 7,7–7,8;
bounce 30 → 40 %. Год к году (10.2025 vs 10.2024) users −67 % [Снимок].
Мобильные: 69 % сессий, **81 % пользователей** [GA4]; 78 % кликов GSC.
Unassigned 27,6 % сессий (цель < 10 %, #2659), ещё 37 сессий с landing
`(not set)` и bounce 92 %.

### 2.2 Воронки — где обрыв

- **Регистрация:** 331 users → `register_cta_impression` 77 users →
  `cta_register_click` 14 → `registration_view` 13 → `registration_complete`
  **11**. Форма конвертирует 85 % от просмотра; узкое место — вход в неё: до
  формы доходят 4 % пользователей. Большинство регистраций — через квестовый
  гейт (13 кликов), а не через CTA сайта.
- **Квесты:** `quest_card_impression` 113 users → `quest_card_click` 18
  (CTR 4 %) → `quest_start` 33 → `quest_point_1_done` **15** → finish **6**.
  **45 % стартовавших уходят, не ответив ни разу**; дальше 15→10→9→7→6 плавно.
  [QFL]: 41 из 127 строк — дефекты словарей/первой точки (верные ответы
  отклоняются, `grodno-royal/kalozha`: один отказ за 22,8 с и игрок исчез).
  Bounce квестовых лендингов 50 % против 30 % у статей; `krakow-dragon` 95 % /
  6,8 с.
- **Создание контента (web):** `content_create_cta_impression` 22 users →
  click **0** → `route_create_started` 1 → `travel_publish` **0** (0 в 08–10).
  При этом по API в августе 66 публикаций не автора 1 — реальный путь
  публикации не измеряется (см. 2.3).
- **Приложение:** `AppInstallBar_Shown` 109 users → Dismiss 39 → Click **3**
  (2,7 %); `app_download_click` 5/мес; установок магазинов нет в данных
  (Play — выгрузка не получена, Apple — один день).
- **Остальное:** favorites 2 users, affiliate click 0 из 14 показов, PDF
  export / email subscribe / share — 0 событий (эмиттеры есть).

### 2.3 Дыры в измерении (instrumentation gaps)

1. Мобильное приложение не измеряется вовсе (native-аналитика отключена, в
   GA4 только stream `web`).
2. Установки магазинов: Play `MISSING_REPORT`, Apple — 1 день.
3. Яндекс.Метрика — токен не настроен с июля.
4. `travel_publish` = 0 при 66 публикациях/мес по API — эмиттер в
   `components/travel/useTravelPublishModeration.ts` не на реальном пути.
5. `content_create_cta_click` 0 при 24 impressions — клик и показ на разных
   поверхностях.
6. `/map` — ни одного события; `/search` — 2 `view_search_results` на 107
   просмотров, нет запросов и zero-results.
7. Шаги квеста типа `any` не пишут телеметрию (20 из 127 строк QFL — «нет
   данных»).
8. Unassigned 27,6 % + `(not set)` — треть сессий без источника.

### 2.4 Почему пользователь уходит — сводка

1. Контент отвечает на запрос, продукт не предлагает следующего шага: 309 из
   383 users новые, 1,03 сессии на пользователя; CTA регистрации видят 23 %
   пользователей, нажимают 4 %.
2. Стена первой точки квеста (2.2) + географическое несовпадение: аудитория —
   Беларусь (yandex.by, топ GSC), каталог — 282 квеста по всей Европе, квесты
   читают из кресла (3–47 с на просмотр).
3. Мобильный вход медленный (LCP 5,2 с на главной, раздел 1.7) при 81 %
   мобильных пользователей.
4. Гостевые действия (план/офлайн/избранное) упираются в экран «С
   возвращением» без объяснения ценности (T-3, A-2).
5. Технические тупики: пустой поиск без результата (S-1), пустые страницы
   квестов без 404 (Q-1), мёртвые slug'и статей с 200 OK из YouTube [AAL].
6. Верх воронки не докручен: запросы с CTR < 1 % («любча» 373 показа,
   «торунь» 205) те же, что в июле.

## 4. Как перепроверить

- Поведение на проде — сценарии из раздела 1 (адреса указаны в каждой находке).
- Lighthouse: `node scripts/lighthouse-produrl.js --formFactor mobile --url https://metravel.by/ --output .codex-temp/lh.json`.
- Аналитика: `npm run stats:ga4 -- --days 30 --channel-breakdown`, `npm run stats:ga4 -- --days 30 --events`, `npm run stats:gsc -- --days 28`.
- iOS: актуальная сборка на симуляторе, вкладка «Карта» без разрешения геолокации.
