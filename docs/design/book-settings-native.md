# Окно настроек PDF-книги в приложениях (#2229)

Короткое решение аналитика, дизайнера и архитектора до кода. Макета Figma нет;
эталон — окно «Настройки фотоальбома» на сайте (`components/export/BookSettingsModal.tsx`).

## Аналитик: какие настройки нужны на телефоне

Весь набор `BookSettings`, тот же, что на сайте: печать книги из приложения идёт тем же
генератором, и сокращённый набор дал бы две разные книги из одного аккаунта. Порядок и
состав блоков повторяют сайт, «детальные» (название, подзаголовок, обложка, оглавление)
так же свёрнуты за кнопкой «Показать детальные настройки».

Хранение последних настроек между запусками на native — **не сохранять**. На сайте ключ
`metravel_pdf_settings` пишется, но не читается: оба места показа окна (каталог и экран
путешествия) всегда передают `defaultSettings`, а чтение срабатывает только без них.
Переносить на AsyncStorage запись, которую никто не читает, — мёртвый код.

## Дизайнер: форма окна

- Полноэкранный `Modal` (`presentationStyle="pageSheet"` на iOS — лист со шторкой;
  на Android — полноэкранное окно с системной кнопкой «Назад» = «Отмена»).
- Содержимое — `ModalSafeArea` (владелец безопасной зоны) → опциональный native
  `NativeModalFormShell`: один полноразмерный `ScrollView` с неизменным узлом формы.
  В обычном состоянии измеренные шапка и подвал закреплены поверх него, а равные
  им внутренние отступы сохраняют доступность первого и последнего поля. При фокусе
  поля, открытой клавиатуре или нехватке высоты для шапки, подвала и одного
  минимального контрола (44 pt / 48 dp) шапка, ошибки и все действия становятся
  частью этой же прокрутки. Поля не перемонтируются; размер доступного текста не
  ограничивается. Измерение хрома одинаковой ширины сохраняется в обоих режимах.
  Фон всех частей берётся из темы.
- Шапка: заголовок «Настройки фотоальбома», «Выбрано путешествий: N» и строка «Будет
  создана книга…», метка «Не сохранено» при правках.
- Порядок блоков (как на сайте): «Порядок путешествий в книге» → «Быстрый старт»
  (`PresetSelector`) → тема (`ThemePreview`) → «Раскладка галереи» (`GalleryLayoutSelector`,
  если галерея включена) → «Показать детальные настройки» (название, подзаголовок со
  счётчиком `N/150`, тип обложки, «Включить оглавление») → «Чек-листы путешественника».
- Выбор из списка (порядок, обложка) — вертикальные строки-радиокнопки во всю ширину,
  а не `<select>` и не горизонтальный ряд: пять вариантов порядка в ряд не помещаются на
  320 pt. Строка не ниже 44 pt, `accessibilityRole="radio"`.
- Переключатели (оглавление, чек-листы) — `Toggle` из `components/ui`; разделы чек-листа —
  `Chip` в переносимом ряду.
- Подвал: «Отмена» (outline), «Превью» (если передан `onPreview`), «Сохранить PDF» (primary);
  действия идут вертикально в этом порядке, каждое во всю ширину контейнера. Это
  работает и в узком iPad `pageSheet`, ширина которого не равна ширине экрана.
  Полные подписи RU/BE/UK/PL/EN центрированы и переносятся без ограничения числа
  строк; высота кнопки определяется содержимым, минимум 44 pt на iOS / 48 dp на
  Android. Подвал не сжимается; форма остаётся в одном `flex: 1` `ScrollView`.
  Нижней безопасной зоной владеет только внешний `ModalSafeArea`.
- Состояния: первое открытие — значения `defaultSettings`; ошибка проверки — красный
  блок над подвалом и подпись у поля, «Сохранить PDF» и «Превью» неактивны; сохранение —
  кнопка с индикатором, повторное нажатие игнорируется; премиум-вариант без премиума —
  настройка не меняется, открывается paywall (аналитика `trackPaywallView`).
- Цвета — только `useThemedColors()`; ширины 320 и 390 pt без горизонтальной прокрутки
  (выбиралки с горизонтальным рядом прокручиваются внутри себя).

## Архитектор: границы

- Общий слой — `components/export/useBookSettingsForm.ts`: состояние `settings`,
  сброс к `defaultSettings` при открытии, проверки (подзаголовок ≤ 150, чек-листы с
  разделом), премиум-гейты (`gallerySettingNeedsPremium`, `isPremiumCoverType`,
  `trackPaywallView`, `requireUnlock`), пресет, признак несохранённых правок, `save` и
  `preview` с тостом ошибки. Без DOM и без `localStorage`.
- Web — `BookSettingsModal.tsx`: разметка и поведение не меняются; ловушка фокуса, Escape
  и блокировка прокрутки страницы остаются только там. После коммита #2238 web-окно
  переведено на общий хук. Load/persist callbacks сохраняют прежние чтение и запись
  `metravel_pdf_settings`; повторной реализации валидации и premium-гейтов нет.
- Native — `BookSettingsModal.native.tsx` с тем же публичным контрактом
  (`visible`, `onClose`, `onSave`, `onPreview?`, `defaultSettings?`, `travelCount`,
  `userName?`, `mode?`) и теми же экспортами типов (`BookSettings`, `ChecklistSection`,
  `PdfThemeName`); нативные части (строки-радио, чек-листы, подвал) —
  `BookSettingsModal.native.parts.tsx`.
- Клавиатура iOS: `automaticallyAdjustKeyboardInsets` полноразмерного ScrollView
  использует реальные координаты окна UIKit, включая `pageSheet`; поверх него нет
  `KeyboardAvoidingView`, ручной высоты клавиатуры или фиксированного смещения листа.
  Android: от RN-высоты клавиатуры вычитается уже наблюдаемое уменьшение Dialog
  относительно скрытой клавиатуры; остаётся только положительный остаток. При
  повороте скрытая базовая высота измеряется заново. Фактически сфокусированное
  поле измеряется относительно неизменного тела формы и раскрывается по доступной
  высоте модального вьюпорта после изменения клавиатуры/вьюпорта. Экранные координаты
  клавиатуры не смешиваются с координатами формы внутри безопасной зоны.
  Shell подписывается на состояние и изменение рамки клавиатуры, включая открытие
  при уже видимой клавиатуре; после закрытия очищает только геометрию и фокус,
  а состояние настроек остаётся у существующего общего хука.
- Три выбиралки (`ThemePreview`, `PresetSelector`, `GalleryLayoutSelector`) берутся как
  есть: у них уже есть native-ветки на `ScrollView`/`Pressable`; годность по виду и касаниям
  подтверждает device-проход.
- `isBookSettingsWindowAvailable()` удаляется вместе с веткой «печать без окна» в
  `ShareButtonsPdfExportBridge.tsx`: окно есть везде, где есть печать.
