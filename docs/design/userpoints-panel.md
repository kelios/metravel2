# «Мои точки»: панель фильтров и действий — #3134

## Принятое решение

Панель справа от карты (web ≥ 1024) и мобильный таб-бар (web < 1024, Android,
iPhone) имеют по одной вкладке **«Фильтры»** и по одной **«Список»**. Вкладка
«Фильтры» содержит сами фильтры, развёрнутые сразу: кнопки «Показать/Скрыть
фильтры» больше нет. Промо-блок «Случайный выбор» свёрнут до одного действия
с одной строкой подсказки. Второго поля поиска и второго переключателя
Карта/Список на экране нет.

До #3134 вкладка называлась «Фильтры карты» и фильтров не содержала (промо,
переключатель, кнопка «Показать фильтры», поле поиска) — три входа в фильтры
и повтор дефекта #489. Нормативный источник дефектов — прод-проба 08.11.2026
(`.codex-temp/userpoints-probe/desktop-filters.png`).

## Состав вкладки «Фильтры» (сверху вниз)

```text
[ Всего 2 656 ] [ Найдено 2 656 ]            ← статистика, числа через formatInteger
[ С картой | Только список ]                 ← только web ≥ 1024: раскладка экрана
[ ⤮ Выбрать 3 случайные точки ]              ← действие; подсказка одной строкой ниже
   Не решили, куда поехать? Случайно выберем 3 точки…
[ ⚙ Управление точками ]                     ← импорт, экспорт, массовые действия
[ ⚌ Показать настройки карты ]               ← только web ≥ 1024 в режиме карты (#1787)
──────────────────────────────────────────
Активные фильтры              [ Сбросить ]   ← блок виден только при активных фильтрах
[Красный ×] [100 км ×]
Подборки ▸ · Радиус ▾ · Цвет ▾ · Категории ▾ ← PointFilters, всегда развёрнуты
```

- Действия — подписанные строки во всю ширину на любой платформе (#1414);
  иконки Feather, тач-таргет 44 dp.
- Переключатель раскладки подписан **по раскладке** («С картой» / «Только
  список»), а не «Карта / Список», чтобы не читаться как дубль вкладок.
- Поле поиска внутри вкладки появляется только в режиме «Только список» на
  широком web (`showSearch`), где нет шапки списка со своим полем.

## Вкладка панели и мобильный таб-бар

| Поверхность | Вкладки | Бейджи |
| --- | --- | --- |
| Web ≥ 1024, режим карты | «Фильтры» · «Список (N)» | у «Фильтры» — число активных фильтров (при 0 нет) |
| Web < 1024, Android, iPhone | «Карта» · «Список» · «Фильтры» | у «Список» — число точек, у «Фильтры» — активные фильтры; ниже 360 px — без иконок (#3133) |

Бейджи сегментов форматируются общим `formatPlaceCountBadge` («999+» выше
порога), как на общей карте (#2217).

## Шапка списка (вкладка «Список»)

```text
[ 🔍 Поиск по названию, адресу, описанию и категории… ] [ ⚙ Управление точками ] [ ↺ Сбросить фильтры ]
```

- «Управление точками» подписана на любой ширине (шестерёнка не «говорящая»).
- «Сбросить фильтры» показывается только при активных фильтрах — без
  disabled-состояния.
- Кнопки «Фильтры» над списком нет: вход в фильтры один — вкладка.

## Что не меняется

- Содержимое `PointFilters` (подборки, радиус, цвет, категории) и логика
  фильтрации.
- Попап точки на карте: после #3131 ряд действий «Страница · Изменить ·
  Удалить · Навигация» помещается без обрезки, индикатор «ещё» живёт в пузыре.
- Доступность настроек карты по поверхностям — `userpoints-map-settings-1787.md`.

## Проверка

- Web 1440: вкладка «Фильтры» показывает фильтры без лишних кликов; выбор
  цвета сужает список и карту, на вкладке появляется бейдж «1».
- На экране один переключатель раскладки («С картой / Только список») и одно
  поле поиска; «Случайный выбор» и «Управление точками» — за один клик из
  вкладки «Фильтры».
- Mobile 390 и 320: вкладка «Фильтры» с теми же действиями и фильтрами;
  над списком подписанная «Управление точками», «Сбросить фильтры» — только
  при активных фильтрах.
- Все локали RU/BE/UK/PL/EN: подписи сегментов не обрезаны.
