### Пенины

Включена петля Соколица–Пиенинки из Кросценко. Расчёт по точному GPX даёт
8,475544501 км, после округления 8,48 км; сумма положительных изменений
высот — 692 м. Указанные в карточке парка 90 и 110 минут сложены в ориентир
200 минут без остановок. Это не обещание продолжительности для каждого
человека и не обозначение лёгкой семейной прогулки.

Снимок численных фактов и метод: `data/travelBooks/pl/route-evidence.json`.
SHA-256 исходного GPX:
`5b12ad01a6fbe7e5faeab98dc9a09943ff21a4ab577f0eb8d98c56bfa0832047`.
412 точек; без сглаживания; горизонтальное расстояние haversine при
R=6 371 000 м. Набор зависит от дискретизации и исходных высот: это расчёт по
опубликованным данным, не геодезическая съёмка. Полный GPX не копируется в
репозиторий, поскольку открытая ссылка сама по себе не устанавливает лицензию
на перераспространение. Достаточны ссылка, хеш, метод и численный результат.

Воспроизведение из корня проекта (Python stdlib, без платных услуг):

```sh
python3 - <<'PY'
import hashlib, json, math, urllib.request, xml.etree.ElementTree as ET
from pathlib import Path
m = json.loads(Path('data/travelBooks/pl/route-evidence.json').read_text())
raw = urllib.request.urlopen(m['sourceUrl'], timeout=30).read()
assert hashlib.sha256(raw).hexdigest() == m['sourceSha256'], 'Источник изменился'
ns = {'g': 'http://www.topografix.com/GPX/1/1'}
p = [(float(n.attrib['lat']), float(n.attrib['lon']), float(n.find('g:ele', ns).text))
     for n in ET.fromstring(raw).findall('.//g:trkpt', ns)]
def hav(a, b):
    x, y = math.radians(a[0]), math.radians(b[0])
    h = math.sin((y-x)/2)**2 + math.cos(x)*math.cos(y)*math.sin(math.radians(b[1]-a[1])/2)**2
    return 2*6371000*math.asin(min(1, math.sqrt(h)))
d = sum(hav(a, b) for a, b in zip(p, p[1:])) / 1000
up = sum(max(0, b[2]-a[2]) for a, b in zip(p, p[1:]))
assert len(p) == m['pointCount'] and p[0] == p[-1]
assert round(d, 2) == m['result']['distanceKm']
assert round(up) == m['result']['elevationGainM']
print(len(p), round(d, 2), round(up))
PY
```

[официальной петле Трёх Корон](https://piepn.gov.pl/szlaki-turystyczne/trzy-korony-ze-sromowiec-niznych-petla)
выделяет участок от ближайшей к Szopka точки до верхней точки трека; минимальное
расстояние от вершин выбранного трека до сегментов этого участка — около 882 м.
Оба SHA, индексы 100–144 и метод сравнения сохранены в `closedSectionComparison`.
Это контроль географического разделения; он не уточняет границы ремонтных работ
и не даёт разрешение на прохождение. Геометрия не заменяет новый
бюллетень: перед выходом проверяется вся актуальная трасса, включая новые
закрытия, а обход к Трём Коронам не предлагается.
