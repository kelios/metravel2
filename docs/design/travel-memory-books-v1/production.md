# Производство книг — поезд B

Редакционные снимки и эталон A2 остаются источниками содержания и физической
геометрии. Изображения и права собраны в `data/travelBooks/rights.json`;
печатные и веб-производные лежат в `data/travelBooks/assets/` вне app-бандла.
Это ещё не публичные издания: неизменяемые manifest и публикацию делает C1.

## Локальная подготовка

Нужны Node-зависимости проекта, Chromium Playwright, Python с `pypdf==6.1.3`
и `reportlab==4.4.4`, а также Poppler (`pdfinfo`, `pdffonts`, `pdftotext`,
`pdfimages`, `pdftoppm`). Все операции локальные, без облачного рендера.

```sh
python3 -m venv .codex-temp/books-production/venv
.codex-temp/books-production/venv/bin/pip install pypdf==6.1.3 reportlab==4.4.4
node scripts/books/media-check.mjs
node scripts/validate-ready-books.mjs --editorial
node scripts/build-ready-books.mjs --check
```

`--check` проверяет источники, права, хеши, профили, HTML и планы сборки;
он не доказывает физическую вместимость текста. Полная компиляция после code
review проверяет загрузку встроенных ресурсов и переполнение перед печатью:

```sh
node scripts/build-ready-books.mjs
node scripts/validate-ready-books.mjs --production .codex-temp/books-production/output/production-index.json --digital-only
```

Другой Python задаётся через `--python <путь>` или `READY_BOOKS_PYTHON`.
Выходы разрешены только в ignored `.codex-temp/`; индекс содержит точные
SHA-256, размеры, число страниц, редакцию и физический профиль каждого файла.
Валидация сопоставляет их с реальными байтами и независимыми измерениями Poppler.
Промежуточный индекс не заменяет ReadyBook и не публикуется как готовый manifest.

## Состав и сборка

На страну и формат создаются 56 внутренних страниц и четыре отдельные стороны
обложки для чтения и подготовки к типографии. Внутренний блок начинается
титулом, а первое место остаётся на чётной левой странице 6. Кириллические
шрифты, фото и QR встроены; сеть при компиляции запрещена.

Для дома основной PDF уже разложен по сторонам A4; повторная «Брошюра» или
подгонка запрещены. Контроль и карта расположения находятся в отдельном PDF.

| Комплект | Лист | Переворот | Сборка |
| --- | --- | --- | --- |
| 150×100, кольца | A4 portrait | длинная сторона | две страницы одна над другой, рез по карте |
| A5, кольца | A4 landscape | короткая сторона | две страницы рядом, рез до 148×210 мм |
| A5, прошивка | A4 landscape | короткая сторона | отдельные тетради 16+16+16+8, сгиб 148,5 мм, внешняя подрезка 0,5 мм |

Тетради вкладываются по отдельности, затем идут подряд. Compact не получает
ложный прошивной вариант: разворот 300 мм не помещается на лист A4 297 мм.
Расположение оборотов рассчитано на указанный переворот; ручную подачу сначала
проверяют одним листом. Линейка 50 мм должна дать 49–51 мм по обеим осям.
Непечатаемые поля принтера не исправляют уменьшением книги.

## Предел цифровой проверки

Проверяются число страниц, все MediaBox/TrimBox/BleedBox, встроенные шрифты
с Unicode mapping, извлечение полного русского текста каждого места, реальное
разрешение растров не ниже 300 ppi, SHA-256 и состав домашних пакетов.
Контактные листы и просмотр всех страниц дополняют численные проверки.

Выходы `print-shop` имеют вылеты и честную маркировку RGB. Они не называются
CMYK, PDF/X или принятыми типографией. Без `--digital-only` валидатор не выдаёт
общий pass: подтверждения точных файлов провайдерами Беларуси и Польши для
обоих форматов остаются зависимостью D1 (#2803). Публичные требования провайдера
сами по себе не означают приём конкретной книги. Бумажный пробник и читаемость
QR с бумаги проверяются отдельно в H1 (#2806).

Повторить производство и цифровую проверку при изменении редакции, медиа,
шрифтов, рендера, раскладки, версии Chromium или PDF-инструментов. После
подтверждения провайдера повторно проверить именно согласованные байты,
профиль цвета, вылеты, переплёт и тираж.
