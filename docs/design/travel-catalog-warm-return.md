# Возврат к просмотренным обложкам каталога

Норматив для `/travelsby`, `/search` и общего `WebMainImage`, 24.10.2026.
Геометрия карточек, contain, цвет полей, управление и плотности сохраняются.
Desktop web и mobile web используют одинаковые состояния:

| Состояние DOM-изображения | Видимый результат |
| --- | --- |
| Выбранный собственный кандидат complete и имеет размеры | Собственное фото открыто до первого paint, включая возврат к карточке |
| Остались пиксели предыдущего путешествия | Нейтральная заливка до готовности собственного фото |
| Готов другой размер, версия или подпись вне активного srcSet | Он не подтверждает готовность активного кандидата |
| Приходит запоздалое событие предыдущего источника | Оно не раскрывает чужую фотографию |

## Подтверждённый механизм

`RightColumn` переиспользует ячейки, `ImageCardMedia` скрывает предыдущий кадр,
а прежний `WebMainImage` проверял кеш-хит пассивным эффектом. Кандидат мог стать
готовым между commit и paint, оставаясь с opacity 0 до следующей проверки.

Baseline продакшена `242bd5c77424b5837c082ccbefda90867f7a240d`: Chrome 149,
аккаунт тестирования 104, плотная сетка, 390×844, DPR3, CPU×4. В первом кадре
возврата у обложек 672/664 были собственный currentSrc, complete=true,
naturalWidth=181 и opacity=0. Двенадцать обращений к кешу передали 0 байт.
Контроль 1440×900 DPR2: 113 кадров, таких скрытых готовых фото нет.

## Проверка

Первый выкат `7fd88a5b4` не прошёл mobile-приёмку: по одному скрытому готовому
кадру в обеих плотностях. Диагностика подтвердила ранний вызов decode, но его
Promise разрешался позже готового currentSrc. IntersectionObserver уже входил
в recovery при complete=true; recovery повторно вызывал decode вместо
немедленной проверки пикселей. Проверка фактической готовности обязательна
непосредственно в этом callback перед любым отложенным восстановлением.
Регрессия должна синхронно раскрыть готовое собственное фото при пересечении,
не вызывая decode и не ожидая таймер или событие load.

Без перехвата page.route и отключения HTTP-кеша: показать карточки, прокрутить
достаточно далеко для переиспользования DOM, затем записать каждый rAF первого
возврата. Обложка учитывается при видимости не менее 25% внутри scroller.
Готовое собственное фото не проходит через скрытый кадр; чужих фото нет.
Проверить desktop/mobile, обычную/плотную сетку, байты повторных обращений,
консоль и ограниченное число img. Cached 200/0 байт не заменяет проверку кадров.

Готовность проверяется в общем renderer по фактическому currentSrc и активным
кандидатам. Проверка до paint и microtask закрывают тёплый возврат; ранний decode
разрешён лишь видимому точному набору источников, ранее успешно показанному.
Подсказки ограничены 256 строковыми ключами, без хранения DOM или растров.
Холодная lazy-загрузка, окно FlashList и native-поведение сохраняются.
