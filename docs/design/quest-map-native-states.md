# Карта квестов: состояния native-экрана (#3424)

Норматив: существующая шапка приложения, один управляющий переход «назад» в
шапке, тело на оставшуюся высоту. Структура общая для Android и iOS. Макеты
показывают существующие элементы; новых строк и оформления не вводят.

```text
Загрузка                       Успешный результат
┌────────────────────────┐     ┌────────────────────────┐
│ ‹ Квесты               │     │ ‹ Квесты               │
├────────────────────────┤     ├────────────────────────┤
│                        │     │                        │
│          ◌             │     │    карта с точками     │
│ Загружаем карту квестов │     │        квестов         │
│                        │     │                        │
└────────────────────────┘     └────────────────────────┘

Сбой первого чтения            Успешный пустой набор
┌────────────────────────┐     ┌────────────────────────┐
│ ‹ Квесты               │     │ ‹ Квесты               │
├────────────────────────┤     ├────────────────────────┤
│                        │     │                        │
│ QuestLandingLoadError  │     │      значок карты      │
│   [Повторить]          │     │ Нет квестов с          │
│                        │     │ координатами…          │
└────────────────────────┘     └────────────────────────┘
```

- Карта использует точки каталога без круга радиуса и кластеров мест из `/map`.
- Координаты дальних городов сохраняются; стартовый вид подгоняет набор точек.
- Native-каталог может опускаться ниже обычного высотного нижнего зума, когда
  иначе полный набор не помещается. При изменении размера набор подгоняется
  заново; радиусная карта сохраняет свой прежний нижний зум.
- Временный фоновый сбой не прячет уже доступные точки.
- Доступное имя native-маркера — существующее название категории, для этой
  поверхности «Квест». Оно назначено самому фокусируемому значку DivIcon.
- Кнопка повтора принадлежит существующему `QuestLandingLoadError`; во время
  повтора она показывает загрузку и не допускает второго нажатия.
- Native-тело не добавляет плавающую или строчную кнопку «назад» ни в одном
  состоянии. На web сохраняются существующая оболочка и возврат к каталогу.
- Приёмка после review: Android-эмулятор — маркеры, дальние города, переход по
  маркеру и единственная кнопка назад; web — сохранность оболочки состояний.
