# Навигация по разделам путешествия — #2024

Нормативные состояния существующей страницы `/travels/:slug` на desktop web
(1366×900) и mobile web (390×844). Исправление восстанавливает подсветку;
порядок секций, подписи, размеры элементов и оформление сохраняются.

| Состояние страницы | Навигация | Контент |
| --- | --- | --- |
| Начало страницы | Активна галерея | Галерея и начало статьи |
| Чтение карты | Активна «Карта» | Карта маршрута |
| Чтение точек | Активны «Точки маршрута», если раздел есть | Список точек |
| Чтение рекомендаций поблизости | Активен пункт «Рядом» | «Рядом можно посмотреть» |
| Чтение последних рекомендаций | Активен пункт популярных маршрутов | «Популярные маршруты» |
| Переход по пункту навигации | Активен выбранный пункт | Соответствующий раздел попадает в область чтения |

На desktop состояние видно в навигации по разделам; на mobile — в доступном
мобильном представлении той же навигации. В каждом представлении активен
один пункт. Разделы могут загрузиться спустя любое время после входа на
страницу: поздняя загрузка не меняет правило подсветки.

Проверка: дождаться более четырёх секунд до прокрутки, пройти страницу до
популярных маршрутов без нажатия на ссылки секций, затем проверить переходы
по пунктам. Снять desktop/mobile screenshots активной навигации и проверить
console. DOM каждой существующей секции должен содержать её
`data-section-key` до первого клика по соответствующему пункту.
