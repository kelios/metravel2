# «Мои точки»: доступность настроек карты — #1787

## Принятое решение

Кнопка «Показать/Скрыть настройки карты» доступна только в широком web
(ширина ≥1024) в режиме карты. Здесь карта и панель фильтров смонтированы
одновременно, а `UserPointsMapWeb` передаёт `MapUiApi`.

На iOS/Android native wrapper не передаёт `MapUiApi`. На узком web вкладки
карты и фильтров монтируются поочерёдно. В отдельном режиме списка панели
настроек нет. На этих поверхностях кнопка отсутствует: выбран вариант (б)
из Task Contract #1787. Подключение native API или сохранение карты между
мобильными вкладками — отдельное расширение функциональности.

## Нормативные состояния

| Поверхность | Карточка управления | Панель настроек |
| --- | --- | --- |
| iOS/Android, любая ширина и режим | Управление точками; Показать/Скрыть фильтры | отсутствует |
| Web <1024, карта/список/фильтры | те же два доступных действия | отсутствует |
| Web ≥1024, отдельный список | те же два доступных действия | отсутствует |
| Web ≥1024, карта, настройки закрыты | дополнительно Показать настройки карты | отсутствует |
| Web ≥1024, карта, настройки открыты | дополнительно Скрыть настройки карты | существующая панель под шапкой |

Схема карточки телефона:

```text
Управляйте сохранёнными местами
[ Управление точками ]
[ Показать фильтры   ]
Поиск по точкам …
```

Действия сохраняют существующие подписи, иконки, порядок и тач-таргеты.
Новых пользовательских строк и изменений состава настроек нет.

## Переходы и проверка

- Широкий web: открыть/закрыть настройки; проверить, что панель действительно
  появляется и исчезает, а управление картой остаётся работоспособным.
- Из открытой панели переключиться в отдельный список и сузить окно:
  не должно оставаться панели без кнопки или кнопки без доступной панели.
- iOS simulator, Android device, mobile web: открыть «Мои точки», проверить
  вкладки карты/списка/фильтров; недоступной кнопки нет, другие действия и
  существующие локализованные подписи доступны.
- Скриншоты и runtime/console evidence собираются в стадии `testing`.
