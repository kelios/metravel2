# Начало и продолжение квеста для гостя

Макет состояний веб-визарда на мобильном (390 × 844) и настольном
(1280 × 800) экранах. Используются существующие кнопки и карточки.
На мобильном интерактивные области не меньше 44 × 44 px.

## До старта гостя

```text
Стартовая точка
Главный вход в парк Горького
Первые 2 задания можно пройти без аккаунта.
Для продолжения войдите или зарегистрируйтесь.
[Начать квест]
```

Пояснение видно рядом с кнопкой до первого нажатия. Число берётся из того же
лимита, который применяет визард. Игрок может попробовать квест сразу.
После лимита сохраняется существующий экран с кнопками входа и регистрации.
У вошедшего пояснение скрыто.

## Продолжение после входа

```text
После второй загадки: [Войти] [Зарегистрироваться]
После входа, если нужно: согласие с условиями → [Продолжить квест]
После согласия: Точка 3 из 10 · Задания: 2 / 7
Осколок Солнца
```

- После переноса видны зачтённые ответы и следующая доступная нерешённая точка.
  Если пользователь уже принял условия, экран согласия пропускается.
- Пока восстанавливается прогресс, показывается состояние загрузки. Старт
  с нулевым счётчиком в этот момент не показывается. При ошибке сохраняется
  возможность повторить восстановление по действующему механизму.
- Прошедшие точки можно открыть вручную. Поздняя синхронизация не перебрасывает
  игрока, который уже продолжил прохождение. Для нового квеста без прогресса
  сохраняется действие «Начать квест».
