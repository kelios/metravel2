# Веб-паттерны MeTravel

Предлагаемый эталон для миграции. Справочник существующих компонентов — [Design system](../DESIGN_SYSTEM.md). Проверка 4 ноября 2026 года опирается на исходники и историю задач. Публичные `/search`, `/places` и `/quests` отвечали HTTP 200. Значения ниже показывают прежнюю геометрию. Для поиска при 1280 и 1440 px использовано также браузерное доказательство #2765. Текущие скриншоты и сравнение с новой геометрией фиксируются при приёмке пилота.

## Что расходится сейчас

| Поверхность | Что найдено | Что берём в работу |
| --- | --- | --- |
| Общая навигация | `CustomHeader` и `BottomDock` уже общие. Пункты `CustomHeaderNavSection` и `BottomDockMoreItem` имеют свои оболочки `Pressable` и назначают ссылочную роль в обработчиках перехода. | Общий вид пунктов и видимый фокус. Проверить реальные `href` у строк, которые ведут на страницу. |
| Поиск `/search` | В старом режиме колонка встроена от 1440 px. При 1280 px фильтры открываются поверх выдачи. Формула 20% окна с ограничением 260–340 px относится только к встроенному режиму. | Сохранить расчёт сетки, резерв первого кадра и восстановление списка из #2759. |
| Места `/places` | `PlacesScreen.styles.ts` задаёт колонке 280 px. `PlacesScreen.tsx` включает компактный режим ниже 760 px. | Убрать отдельное решение о ширине и пороге, сохранить категории, поиск и сброс. |
| Квесты `/quests` и вложенные маршруты | `QuestsStyleMetrics.ts` задаёт 260 px в диапазоне 768–1023 px и 340 px на широкой ветке. | Карта `/map` | Собственные `FiltersPanel`, мобильная компоновка и статический каркас. Размер и режим панели влияют на доступную область карты. | Подключить общий заголовок, строки и действия. Сравнить поведение полноэкранной карты до принятия общей колонки. |
| Детали путешествия | `CompactSideBarTravel` представляет якорное оглавление со своим состоянием активной секции. | Общий вид строки и фокус. Сохранить якоря и обновление активного пункта при прокрутке. |
| Поездки, профиль, настройки, сообщения и избранное | Смешанные типы экранов. Полный обход ещё предстоит. | Назначить каждой поверхности тип страницы или документированное исключение. |

Пилот сопоставляет панели фильтров, а также отдельно проверяет общую навигацию и якорное оглавление. Ширина фильтров, оглавления и глобальных пунктов имеет разные причины и задаётся по роли.

`npm run design:verify` завершился без ошибок и сообщил о 82 совпадениях с шаблоном hex в 34 файлах. Среди совпадений есть комментарии и специальные поверхности карты. Разбирать их нужно по роли цвета в мигрируемой зоне, с проверкой светлой и тёмной тем.

## Макет панели фильтров

Геометрия пилота задана в `components/layout/catalogFilterPanelGeometry.js`. Значения проверяются на 1024, 1280 и 1440 px до подключения следующих разделов.

| Ширина окна | Как выглядит |
| --- | --- |
| 1280 px и шире | Колонка 320 px слева, отступ до контента 24 px. |
| 1024–1279 px | Колонка 280 px слева, отступ до контента 16 px. |
| Уже 1024 px | Кнопка «Фильтры» рядом с поиском. Панель открывается по требованию через существующий доступный sheet или drawer. Результаты используют ширину окна. |

```text
Широкий экран
┌ Фильтры ────────────┐   ┌ Поиск / активные фильтры / сортировка ─┐
│ Группы фильтров     │   │ Результаты или каркас загрузки        │
│ …                  │   │ …                                    │
│ Сбросить            │   │                                      │
└─────────────────────┘   └──────────────────────────────────────┘

Телефон
[ Поиск                     ] [ Фильтры ]
[ Активные фильтры                    ]
[ Результаты                          ]

Открытые фильтры
[ Фильтры                      Закрыть ]
[ Группы фильтров                     ]
[ Сбросить ]       [ Показать ]  ← если раздел применяет выбор явно
```

- Панель и список сохраняют положение при переходе с каркаса загрузки на контент. Скролл страницы и вложенная прокрутка не прячут последние элементы. Учитываются мобильный док, safe area и согласия.
- Внутренний отступ панели 16 px, между группами 16 px, внутри группы 8 px. Текстовые строки растут по высоте при переносе. Цель касания на вебе от 44×44 CSS px.
- У узкой панели есть доступный заголовок, явное закрытие, Escape и возврат фокуса. Сбрасывается тот же набор фильтров, что до миграции. Действия «Показать», закрытие по выбору и живое обновление зависят от текущего поведения раздела.
- Состояния эталона — закрыто, открыто, выбранное значение, загрузка, пустой результат, ошибка с повтором. Состояние разрешения на геолокацию показывается там, где его уже использует карта или квесты.

## Макет действий, ссылок и строк

| Роль | Внешний вид и поведение |
| --- | --- |
| Основное, вторичное и опасное действие | `Button` с семантическим вариантом. Видимая подпись переносится. При загрузке сохраняется размер, повторное действие исключено. Опасное действие следует текущим правилам подтверждения. |
| Действие с одной иконкой | `IconButton` с доступным названием и видимым фокусом. |
| Внутренняя ссылка | Видимая ссылка в тексте либо целиком кликабельная строка с адресом. Обычный клик, Enter, контекстное меню и открытие в новой вкладке. Активный пункт отличается фоном и доступным состоянием. |
| Внешняя ссылка | Сохраняет оформление ссылки. Учитывает принятую политику URL и открытия. |
| Якорь в оглавлении | Ссылка на секцию, видимое выделение по прокрутке. Длинные заголовки доступны целиком. |
| Фильтр, раскрытие, вкладка | Выбранное или раскрытое состояние различимо по оформлению и сообщается вспомогательным технологиям. Пункты сохраняют собственные семантические роли. |

Каталог показывает рядом обычное состояние, фокус, hover для мыши, нажатие, выбранное состояние и недоступность там, где они применимы. Для кнопок и панелей есть загрузка. Для экранов показываются реальная общая карточка и варианты «пусто», «загрузка», «ошибка».

## Приёмка миграции

| Проверка | Доказательство |
| --- | --- |
| Mobile web в первую очередь | 390 px, дополнительно 320 px для длинных подписей. Открыть и закрыть фильтры, применить выбор, вернуться из результата. Нет обрезанных действий и горизонтального скролла. |
| Desktop web | 1280 px для сравнения панелей, 1023/1024 для смены режима, 1440 для исторической регрессии поиска. Холодный первый кадр и после гидратации, Tab/Enter/Escape, обычный и модифицированный клики. |
| Темизация и локали | Светлая и тёмная темы на примерах. Проверка ключей RU/BE/UK/PL/EN, длинная подпись на узком экране. Сезонный режим проверяется при затрагивании общей хромированной оболочки сайта. |
| Охват и изоляция | Для каждого выбранного маршрута записаны используемые компоненты, состояния и исключения. В production нет маршрута, sitemap-записи и загрузки примеров каталога. |

Фиксировать скриншоты и консоль на стадии приёмки видимых изменений. Визуальный допуск по положению колонки между каркасом и контентом при той же ширине — ±1 CSS px. Для осмысленно разных режимов сравниваются их собственные эталоны.
