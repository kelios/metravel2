# Каталог: отзывы и срез «С отзывами» — #1792

Нормативный макет состояний общего интерфейса. Используются существующие
строки фильтров, счётчики, цвета, отступы и карточки каталога.

## Desktop web, 1280 px

```text
Фильтры                     Каталог квестов
  Для детей                 ┌──────────────┐ ┌──────────────┐
  Велоквесты                │ Обложка      │ │ Обложка      │
  С отзывами           1    │ Название     │ │ Название     │
  Страны / города           │ Метаданные   │ │ Метаданные   │
                            │ [Отзывы: 1]  │ │              │
                            └──────────────┘ └──────────────┘
```

При нуле отзывов чип отсутствует целиком, без заглушки или резервирования
дополнительной строки. Геометрия обложки, название и метаданные сохраняются.
Строка «С отзывами» выбирается и отображает счётчик квестов, а не отзывов.
После выбора в результатах только карточки с `ratingCount > 0`.

## Mobile web, 390 px

```text
Каталог квестов                  [Фильтры]
Панель фильтров:
  С отзывами                         1
┌─────────────────────────────────────┐
│ Обложка                             │
│ Название                            │
│ Метаданные          [Отзывы: 1]      │
└─────────────────────────────────────┘
```

Срез доступен через существующую кнопку открытия панели фильтров. В панели
используется такая же текстовая строка со счётчиком, как на desktop.
Длинные переводы используют существующий перенос; горизонтального переполнения
страницы нет. В телефонной полосе карточки при нуле нет чипа отзывов.

## Матрица состояний

| Данные | Чип карточки | Срез каталога | Средняя оценка |
|---|---|---|---|
| У всех квестов 0 отзывов | Отсутствует | Не смонтирован | Отсутствует |
| У одного квеста 1–2 отзыва | Есть у этого квеста | Видим, выбирает этот квест | Отсутствует |
| У квеста 3+ отзыва | Есть | Включает этот квест | Прежнее правило ≥3 |
| Последний отзыв исчез после выбора среза | Отсутствует | Исчезает; выбор сбрасывается на все квесты | Отсутствует |

Чип открывает существующую читалку; её форма и разметка не меняются. Общее
условие показа действует также на Android/iOS. Локали: RU/BE/UK/PL/EN.

## Визуальная приёмка

На локальном стеке с реальными ответами API: desktop 1280 и mobile 390,
общий каталог и выбранный срез, нулевой и положительный набор, открытие
читалки реального отзыва. Снимки экрана и ошибки console/network записываются
при testing в ignored `test-results/` или `.codex-temp/`. Ожидаемые локальные
404 старых S3-обложек отмечаются отдельно от ошибок изменённого интерфейса.
