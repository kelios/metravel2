# Книги путешественника v1 — нормативный дизайн

Дата: 26.10.2026. Это спецификация и схема макетов; финальные фото, иллюстрации и печатные пробы создаются задачами релиза. Контракт: `docs/features/travel-memory-books.md`.

## Печатная серия

Тихая композиция фотоальбома: крупное узнаваемое место, короткий рассказ, простор для памяти. Беларусь и Польша имеют общую сетку; страна различается подписью, акцентом, изображениями и картой. Шрифты с открытой лицензией и кириллицей: исходный кандидат Noto Serif для заголовков, Noto Sans для подписи/текста; окончательный файл шрифта и лицензия фиксируются перед сборкой. Не растрировать весь текст ради обхода шрифтов.

| Параметр | Compact | Album |
| --- | --- | --- |
| Обрезной размер | 150×100 мм, landscape | 148×210 мм, portrait |
| Основной переплёт | кольца / пружина с запасом | кольца / пружина с запасом |
| Безопасное поле | 5 мм | 5 мм |
| Внутреннее поле | 15 мм с зеркалированием | 15 мм с зеркалированием |
| Вылеты типографии | исходно 3 мм; конкретный профиль может 2 мм | то же |
| Заголовок | 13–16 pt, максимум 2 строки | 19–24 pt, максимум 2 строки |
| Основной текст | не меньше 9 pt, интерлиньяж 1.3 | 10.5–11 pt, интерлиньяж 1.35 |
| Фото пользователя | 70×100 мм, горизонтально | рамка 108×158 мм для фото до 102×152 мм |
| QR | от 18×18 мм + тихая зона | от 20×20 мм + тихая зона |

QR содержит короткий постоянный URL/координаты, не длинный произвольный текст. Размер модуля, контраст и работа с бумажного пробника обязательны; номинальные миллиметры сами по себе не доказывают читаемость. Координаты и человекочитаемый адрес находятся рядом.

Текст проверяется на реальном физическом размере. При переполнении редактор сокращает текст или меняет распределение в четырёхстраничном блоке; шрифт ниже минимума и скрытое обрезание недопустимы.

## Обложка и порядок

Лицевая обложка: MeTravel, название страны, подзаголовок серии, крупное изображение/композиция реальных мест, «12 мест • книга воспоминаний», формат и язык на карточке сайта. Нижний информационный блок занимает не больше четверти обложки.

Оборот/внутренние стороны: владелец книги, как связаться при потере (поле заполняется вручную), краткая легенда условных обозначений, версия/сайт. Не печатать личные данные по умолчанию.

56 внутренних страниц, обложка отдельно. Титул p1 справа; p2–3 — инструкция; p4–5 — содержание/карта. Места p6–53: по четыре страницы на место. На p54–56 — свободная память/чек-лист/выходные данные. Источники каждого места доступны по короткой ссылке и в редакционном реестре. Не полагаться только на QR для основного текста.

## Разворот места: схема

```text
Чётная левая страница                  Нечётная правая страница
┌──────────────────────────────┐       ┌──────────────────────────────┐
│ № / локальное название       │       │ Дата / с кем                 │
│ МИРСКИЙ ЗАМОК                │       │                              │
│ ┌──────────────────────────┐ │       │ ┌──────────────────────────┐ │
│ │ Фото или достоверная     │ │       │ │ Место для своей          │ │
│ │ иллюстрация объекта      │ │       │ │ фотографии               │ │
│ └──────────────────────────┘ │       │ └──────────────────────────┘ │
│ Краткая история              │       │ Подпись / моё впечатление    │
│ Факт • Легенда (помечена)    │       │                              │
│ Координаты / вход / QR       │       │ «Я хочу запомнить…»          │
└──────────────────────────────┘       └──────────────────────────────┘
       у корешка 15 мм                       у корешка 15 мм
```

Это схема распределения, не обещание вместить одинаковый объём в разные форматы. На compact левая страница использует две колонки: изображение примерно 56×48 мм слева и текст справа, заголовок сверху; факт/координаты/QR снизу. Справа рамка минифото 100×70 мм, короткая дата и подпись. Длинные впечатления — следующий разворот. На A5 изображение примерно 118×68 мм, затем рассказ/факт и нижний блок навигации; справа рамка 108×158 мм и короткая подпись.

Следующий разворот: слева «Мои впечатления» с ненавязчивой линейкой через 6–7 мм, короткими подсказками «Что удивило», «Что посоветую», «Хочу вернуться»; справа «Билет, открытка, ещё один кадр» с пустым полем. Это даёт место для памяти без превращения страницы в анкету. Габарит открытки на A5 проверяется отдельно; на compact обычная открытка — отдельный вкладыш, а не обещание её вклеить целиком.

Места для вклейки обозначаются тонким контуром, надпись внутри небольшая и не остаётся видимой после вставки снимка. Полосы для отверстий не заняты изображением, QR, текстом или рамкой фото. Кольца не должны прорезать важное содержимое.

## Инструкции и наклейки

Инструкция начинается с выбора: «Какая книга / где печатаю / как собираю», затем показывает ровно подходящий файл. Схемы для ready-imposed A4 не предлагают повторную опцию «Брошюра». Контрольный лист содержит 50-мм линейку, стрелку «верх», номер лица/оборота и тестовую пару страниц.

Compact: две страницы 150×100 мм одна над другой в A4 portrait; центрирование оставляет поля для реза. 300-мм сгибной разворот на A4 не показывать. A5: сборка кольцами либо тетради 16+16+16+8 с внешними номерами/метками, проверенная попарная печать. Половина A4 по ширине — 148,5 мм; точные 148 мм получаются после обрезки внешних 0,5 мм либо предварительной обрезки A4 до 296 мм. Белые края допускаются и показаны в предпросмотре домашнего варианта.

Наклейки: два A4 листа на страну. Лист 1 — 12 марок мест, ориентир 35×35 мм; лист 2 — даты/«был здесь»/«любимый кадр»/простые иллюстрации серии. Стартовый вариант имеет контуры ручной резки и безопасные поля 10 мм. Вариант готовых этикеток требует артикула и контрольного теста. Наклейки/печать остаются редакционным RU контентом.

## Экран каталога

Mobile 320–390 px: заголовок/короткое объяснение → две карточки одна под другой → «Как напечатать» → будущие серии отдельным информационным блоком. На desktop: те же карточки в две колонки. Карточка содержит обложку, страну, русский язык, 12 мест, два размера и «Посмотреть книгу». Нельзя обещать заказ/цену/партнёра, которых ещё нет.

Карточка издания: заголовок/обложка → «Что внутри» → кнопка полного просмотра → размер книги и совместимое фото → выбор файла по назначению → инструкция/наклейки → типографии. На mobile основное действие доступно после понятного выбора формата; фиксированная панель, если появится, не перекрывает текст/системные отступы. В выборе формата видны реальные размеры, а не только названия «Маленькая/Большая».

## Предпросмотр

- Одна фактическая страница на mobile; разворот на desktop. Клавиатурные «предыдущая/следующая», номер страницы, содержание и масштаб.
- Превью из той же ревизии готового PDF. Компактный формат не подменяется увеличенным A5. Домашняя раскладка показывается отдельно от читаемого издания.
- Текстовое содержание и список мест доступны без работы с графическим полотном. Кнопки минимум 44 px, видимый focus, имена в i18n.
- Loading: нейтральный placeholder заданной геометрии. Error: понятная причина, повтор и ссылка на скачивание при наличии файла. Empty: «Издание ещё готовится», без активной кнопки несуществующего PDF. Offline: ранее скачанный файл остаётся обычным самодостаточным PDF; сайт не обещает офлайн-кэш без реализации.

## Выбор типографии

Страна → город → «Самовывоз здесь / доставка из другого города». Затем формат, тираж и проверенные возможности поставщика. Видны дата проверки, минимальный тираж, переплёт, готовность профиля, приём RU PDF и язык общения. `unknown` показывается как «нужно уточнить», не зелёная галочка.

Основные действия v1: «Скачать пакет» и «Открыть сайт типографии»; короткая польская записка копируется отдельно. Прямое «Отправить заказ» появляется только после партнёрской интеграции и отдельного согласия. Не добавлять поля адреса/телефона для последующего несуществующего заказа.

## Нормативная приёмка дизайна

Эта схема задаёт порядок, подписи, физические ограничения и состояния. Задача A2 создаёт финальные версионированные макеты двух обложек и четырёх representative spreads (2 страны × 2 размера) с настоящим проверенным материалом. До B2 они проверяются на вместимость текста, корешок и реальные фото.

Runtime сравнение сайта в `testing`: mobile 390 px (и ограничение 320 px) → desktop 1440 px; screenshots каталога, карточки, предпросмотра и ошибки, console/network. Физическое сравнение: рулетка/линейка, обычные фото 100×150 и 102×152, открытка, письмо ручкой, перевороты и толщина вклеек. Планировочный wireframe не заменяет эти доказательства.
