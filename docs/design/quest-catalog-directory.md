# Компактный указатель каталога квестов

Экран: `/quests` и языковые хабы. Mobile web (390 px) и desktop web (1980 px).

Нормативный порядок: сетка карточек → FAQ → указатель. Фильтры, поиск и посадочные страницы сохраняют прежние правила показа указателя.

Закрытое состояние:

```text
▸ Квесты по странам
▸ Квесты по городам
▸ Квесты каталога
```

После раскрытия городов:

```text
▸ Квесты по странам
▾ Квесты по городам
  Августов · Акко · Алания · Алматы · …
▸ Квесты каталога
```

Это схема, а не новые тексты: видимые подписи берутся из существующих переводов RU/BE/UK/PL/EN. Каждый непустой раздел раскрывается независимо, закрыт при первом открытии, сохраняет заголовок второго уровня. Область активации не меньше 44 px по высоте, видимый фокус; Enter/Space, мышь и касание работают и без JavaScript. Нативный браузерный маркер раскрытия не является отдельной кнопкой.

Все ссылки остаются в серверном HTML, после раскрытия видны и доступны клавиатуре. Пустой раздел не создаётся. Loading/error/permission states не добавляются: указатель использует уже полученные данные. Указатель не заменяет карточки и не сбрасывает прокрутку каталога.
