# Состояния медиа и запросов — спринт 35

Нормативные поверхности: desktop web 1440×900 DPR1, mobile web 390×844 DPR3.
Композиция, размеры слотов, подписи, alt и действия сохраняются.

Главная (#3437): серверный снимок показывает тексты и ссылки квестов, слот
обложки сохраняет прежнюю геометрию с нейтральной заливкой. До получения
манифеста он не запрашивает запасную ландшафтную картинку. После ответа API
появляется квадратная обложка в том же слоте. При ошибке API доступна прежняя
запасная обложка. Свежий кеш каталога показывает медиа сразу. Изображения
локального экспорта используют единственный URL без параметров ресайза.

Статья (#3439): состояние загрузки, ошибка, заголовок, хлебные крошки и
сохранённая офлайн-статья имеют прежний вид. Экран и хлебные крошки используют
одну загрузку. Старое фото из S3 показывается через принадлежащий сайту прокси;
его геометрия и авторский alt не меняются.

Тело путешествия (#3438): узкие фото с обтеканием текстом и полноширинные фото
сохраняют свои позиции и размеры. Меняется только выбранный файл для узкого
слота. На телефоне поток фото остаётся прежним. Серверный остров и полный
рендер должны выбирать одинаковый размер и не запрашивать второй вариант.

Проверка в testing: снимки обеих ширин, initial + пять экранов прокрутки,
проверка консоли, URL/статусов/байт запросов и naturalWidth/clientWidth.
Исходный замер сохранён в `.codex-temp/s35-media/before*.json`; он является
сырым evidence, а этот документ — устойчивым описанием нормативных состояний.
