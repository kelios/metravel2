# Страница страны и вход из каталога — #1989

Нормативный макет исправления, 20.09.2026. Используются существующие
карточки, цвета, шрифты и отступы каталога. Содержимое квестов не меняется.

## Строка страны

```text
┌─────────────────────────────────────────────┐
│ [Флаг Беларусь →]       [69 квестов   ⌄]     │
└─────────────────────────────────────────────┘
       ссылка             кнопка сворачивания
```

- Desktop web и мобильная панель фильтров: название страны — настоящая
  ссылка на `/quests/country/belarus`; счётчик и шеврон — отдельная кнопка.
- Каждая область нажатия не меньше 44 × 44 px. Нажатие ссылки закрывает
  мобильную панель и открывает страну; кнопка меняет только список городов.
- Развёрнутая и свёрнутая кнопка сообщают `expanded`; ссылка имеет имя
  «Все квесты страны Беларусь — 69 квестов» с переводами RU/BE/UK/PL/EN.
- Право на ссылку определяется общей моделью лендингов: минимум два города
  после объединения по каноническому alias. В остальных случаях, а также
  в native-каталоге, вся строка остаётся одной кнопкой сворачивания.

## Сетка лендинга

```text
            центр страницы
     ┌─────────────────────────┐
     │ Заголовок, города, текст│
     │                         │
     │ [карточка]  [карточка]  │
     │ [карточка]  [карточка]  │
     └─────────────────────────┘
```

Контент ограничен 840 px, внешние отступы — по 24 px. На широком экране
колонка центрируется. Между карточками — 32 px. Модель и сетка используют
одно число колонок; ширина карточки заполняет трек, включая промежуточные
размеры и экраны с полосой прокрутки. Размеры основного `/quests` сохраняются.

| Ширина viewport | Контент без полосы прокрутки | Колонок | Карточка |
| --- | --- | --- | --- |
| 390 | 342 | 1 | 342 |
| 768 | 720 | 1 | 720 |
| 839 | 791 | 1 | 791 |
| 840 | 792 | 2 | 380 |
| 1024 / 1440 | 840 | 2 | 404 |

Тот же контракт применяется к посадочной города, включая единственный квест.
Проверка: Беларусь и Эстония, desktop 1024/1440 и mobile 390; дополнительно
768/839/840 для границы числа колонок. В браузере ширина карточки должна
совпадать с шириной CSS-трека в пределах 1 px, между соседями остаётся только
`gap`, горизонтальная прокрутка отсутствует. После перехода из мобильной
панели страница прокручивается. Состояния загрузки и пустого каталога
сохраняют существующее поведение.
