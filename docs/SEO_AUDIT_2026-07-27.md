## 1. P0 — авария: travel-страницы отдают noindex-заглушку

### Доказательства (27.07)

| Проверка | Результат |
|---|---|
| 20 случайных URL из sitemap | **20/20** → `<title>Путешествие не найдено \| Metravel</title>` |
| robots-мета на них | `noindex, follow` |
| `npm run test:seo:prod` | **193/301 passed, 108 failed** (нет canonical, og:*, twitter:* на всех travel-URL) |
| `/travels/{slug}/index.html` (прямой путь) | **200, корректный** title/canonical/og — SSG-файлы целы |
| `/quests/{city}`, `/article/{id}`, `/` | работают штатно |
| sitemap.xml | 635 URL, из них **397 travel** — Google обходит их и получает noindex |
| last-modified заглушки | **26.07.2026 21:31 GMT** |

Затронуты в том числе все топ-страницы: `ozero-glubokoe…` (206 кликов/28 дн.),
`chto-posmotret-v-oshmianakh…` (88), `plyazhi-nedaleko-ot-krakova` (85),
`park-grudek…` (83), `smolevud…` (82), `zakshuvek…` (79).

### Механика

Запрос на «чистый» URL `/travels/{slug}` не доходит до per-slug файла и отдаёт
fallback-шаблон `/travels/[param].html`, который генератор намеренно помечает
`noindex` (`scripts/generate-seo-pages.js:2707`).

Причина — не сборка, не контент и **не фронтовый nginx-конфиг**:

- per-slug HTML на диске **есть** (прямой запрос `/index.html` отдаёт полную статью);
- правило во фронт-репо корректно — `nginx/nginx.conf:268`
  `try_files $uri.html $uri/index.html $uri /travels/[param].html;`;
- но ответ на сломанном URL приходит **без** `Cache-Control: no-store`, `Pragma`,
  `Expires` и `Access-Control-Allow-Origin`, которые этот location обязан добавлять,
  а прямой `/index.html` их отдаёт — значит запрос обрабатывается не им.

Точная первопричина зафиксирована в тикете **#1090** (заведён 26.07 по прод-смоуку):
Django-вью `public_travel_slug_view` отвечает заголовком
`X-Accel-Redirect: /__internal/travel-shell`, а `deploy/prod/nginx/nginx.conf` (файл
бэкенд-репозитория) резолвит этот внутренний URI **только** в `/travels/[param].html`,
минуя `/travels/<slug>.html`. То есть путь `/travels/<slug>` вообще не обслуживается
правилами из фронтового `nginx/nginx.conf` — он перехватывается бэкендом.

### Что делать

Работа целиком бэкендовая и уже описана в #1090 (assignee `backend-owner`,
urgency `highest`): починить связку `public_travel_slug_view` + внутренний
nginx-location так, чтобы текущий публичный slug отдавал свой SSR-файл, сохранив
301-редиректы алиасов и 404 для приватных/несуществующих.

Проверка после починки (можно запускать из фронтенд-workspace):

1. `npm run test:seo:prod` — ожидание 301/301 (сейчас 193/301).
2. Точечно: `curl -A Googlebot https://metravel.by/travels/ozero-glubokoe-samoe-prozrachnoe-ozero-v-belarusi`
   — заголовок статьи вместо «Путешествие не найдено», robots без `noindex`.
3. `npm run stats:index` — индексация удержана на ≥291/306.
4. Только после этого — принудительная переиндексация топ-30 (GSC + `npm run indexnow`).

**До починки не запускать ежедневную подачу URL в индекс**: она ускорит обход и,
следовательно, деиндексацию.

### Цена промедления

Дневной срез GSC до 26.07 включительно ещё рекордный (26.07 — 87 кликов, 3320
показов), падения в данных пока не видно из-за лага GSC 2–3 дня. Ущерб линеен по

«Исключено тегом noindex», и возврат в индекс занимает недели.

## 3. Что улучшать в контенте (по убыванию отдачи)

### P1 — кластер «застряло на второй странице»

Крупный, стабильный спрос на позициях 9–11: страница показывается, но её почти не
видно. Это самая большая контентная возможность сайта.

| Страница | Показы/28 дн. | Клики | Позиция | Спрос |
|---|---|---|---|---|
| `/travels/albaniya-vler-gorod-dvuh-morey` | 3 604 | 30 | 8.2 | влера 985 + влёра 334 + влёра албания 206 + албания влера 133 |
| `/travels/lyubcha-lyubchanskiy-zamok` | 1 287 | 5 | 10.4 | любча 472 + любчанский замок 356 + любча замок 91 |
| `/travels/morskoe-oko-v-mae-ozero-v-tatrakh-polsha` | 1 359 | 7 | 8.8 | морское око 174 + закопане морское око 24 |
| `/travels/torun-staryi-gorod-i-muzei-prianika-polsha` | 407 | **0** | 10.4 | торунь 219 + город торунь 14 |
| `/travels/zamok-ogrodzenec-skalnyy-gorod-podzamche` | 426 | 5 | 8.4 | замок огродзенец 158 |

Здесь работает не мета, а вес страницы по теме: расширение под сопутствующие
подзапросы (как добраться, цена/часы, сезон, что рядом), внутренние ссылки с
топ-статей (Глубокое, Ошмяны, пляжи Кракова, закшувек) и актуализация даты.
Диагноз среза 18.07 «проблема позиции, а не сниппета» для Влёры подтверждён:
CTR 0.3–0.97% нормален для позиции 10. Подъём Влёры с 10 на 5 — это ~100 кликов/мес
вместо 30 на том же спросе.

Отдельно: `morskoe-oko-v-mae` — «в мае» в заголовке работает против летнего интента,
кандидат №1 на переименование через `seo-rename.js` (301 уже поддержан).

### P2 — 0 кликов при живых показах

25 страниц имеют ≥40 показов и **ни одного клика**. Характерная подгруппа —
статьи с короткими безынтентными заголовками:

| id | title | Показы | Клики | Позиция |
|---|---|---|---|---|
| 413 | «Сандомир» | 124 | 0 | 9.3 |
| 200 | «Лида. Лидский замок.» | 55 | 0 | 14.7 |
| 450 | «Подкарпатское воеводство» | 53 | 0 | 12.0 |
| 213 | «Грузия. Тбилиси-Батуми» | 52 | 0 | 11.4 |
| 438 | «Нижняя Силезия» | 45 | 0 | 8.4 |

Заголовок из одного топонима не отвечает ни на один пользовательский вопрос.
Переименование по формуле «топоним + что посмотреть/как добраться + ≤60 симв.»
через `seo-rename.js` (создаёт 301 и стаб старого слага) — дешёвая и уже
разблокированная работа.

Сюда же — `/travels/nesvizhskiy-zamok-radzivillov`: 715 показов, 1 клик. Страница
ранжируется только по «расстояние от Минска до Несвижского замка» (153 показа) и
«несвижский замок координаты», то есть Google считает её справкой о расстоянии, а
не материалом о замке. Нужен разворот содержания под основной интент.

### P3 — длинные заголовки (155)

Прошлый срез считал это заблокированным — блокера нет. Но приоритет ниже, чем
казалось: длина сама по себе не мешает (id 133, len 64 — 34 клика; id 132, len 93 —
40 кликов). Чинить стоит только те, что режут ключ служебным префиксом и не
собирают кликов — 23 статьи с паттерном «Маршрут на один день. X» /
«Веломаршрут на N дня. X», начиная с тех, у которых есть показы и 0 кликов
(id 247, 254, 421, 303, 459).

### P4 — квесты: спроса нет

74 квест-страницы показываются в поиске (цель «≥15 страниц с показами»
перевыполнена), но это 409 показов и 13 кликов за 28 дней. Индексация перестала
быть узким местом — узкое место в том, что запросов на «квест по городу X» почти не
существует. Дальше вкладываться в SEO квестов бессмысленно; либо переупаковка под
существующий спрос («что посмотреть в X за один день», «маршрут по X пешком»), либо
продвижение квестов не через поиск.

### Чего не делать

- Не трогать статьи, у которых уже нормальный CTR по позиции (Глубокое, Ошмяны,
  Грудек, гарнизон Дальний) — там докручивать нечего.
- Не запускать массовое переименование одним батчем: `seo-rename.js` меняет slug,
  каждая пачка должна отстояться и попасть в переиндексацию.
- Не считать любые контентные правки применёнными до прод-пересборки: они попадают
  в выдачу только после деплоя.

## 4. Инструментальный пробел

(`build-prod.sh`: FE-IDX-1, проверка `<h1>`, `verify-static-travel-seo.js`), и
пост-деплой проверка (`post-deploy-seo-check.js`), и прод-смоук

однократно в момент деплоя — ни один не следит за прод-выдачей постоянно.
