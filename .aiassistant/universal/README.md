# MeTravel Local в PhpStorm

Один ACP-агент для локальной Qwen, работы с репозиторием и генерации черновиков
картинок через FLUX. Агентный цикл предоставляет OpenCode **1.19.6**; сама Qwen
выбирает инструменты и готовит ответы. Это отдельный режим **MeTravel Local
(Qwen + FLUX)** в AI Chat, а не обычный Chat с подключённой моделью.

## Запуск

1. Открыть MeTravel в PhpStorm → AI Chat → меню режима → **MeTravel Local
   (Qwen + FLUX)**. Начать новый чат для новой задачи.
2. Описать результат, конкретный scope и критерий проверки. Агент может читать и
   редактировать файлы, запускать команды и обращаться к MCP.
3. Подтверждать запросы инструментов после проверки конкретного действия.
   Удаление карточки/спринта требует отдельного подтверждения.

Примеры:

```text
Найди причину падения этого теста, исправь только соответствующий util и
запусти узкую проверку. Сначала покажи task-owned paths. Без деплоя.

Прочитай карточку #3193 и требования к переводу. Подготовь локальный черновик,
проверь структуру и перечисли сомнительные ответы. Не публикуй перевод.

Сгенерируй через локальную FLUX черновик: рыжая собака у лесного ручья,
утренний свет, фотореализм, без надписей, 512×512. Верни ссылку на PNG.
```

## Установленные зависимости на этой машине

- OpenCode: `~/metravel-ai/tools/opencode/node_modules/.bin/opencode`.
- Python с MCP: `~/metravel-ai/tools/flux-mcp-venv/bin/python`.
- Node 22: `/opt/homebrew/opt/node@22/bin` автоматически добавляется в PATH агента.
- Qwen: `http://127.0.0.1:18088/v1`, модель `metravel-local`, контекст 32768,
  выход до 6144 токенов. Только провайдер `local-qwen`, без облачного fallback.
- Мост FLUX: `../flux/server.py`; исполняемый MFLUX и веса находятся в
  существующей установке `~/metravel-ai/`.
- Реестр IDE: `~/.jetbrains/acp.json`; шаблон записи — `phpstorm-acp.json`.

`run.py` проверяет Qwen и при необходимости запускает установленный сервис
`by.metravel.local-qwen`. Запускатель находится вне защищённой macOS папки
Documents: `~/metravel-ai/tools/local-qwen-service/start_coder.py`.
Диагностика нового запуска — `~/Library/Logs/MeTravelAI/qwen-error.log`.
Сервис освобождает память в простое, чтобы FLUX могла работать на 24 GB RAM.
Первое обращение и длинные запросы могут занимать минуты; один сервер обслуживает
запросы последовательно.

## Инструкции и инструменты

`base.json` — редактируемый профиль. `metadata.json` и `opencode.json` генерируются
из текущих канонических источников; не редактировать их вручную.

- AGENTS.md загружается средой; `instructions.md` содержит короткий router.
- 105 канонических скиллов, 64 роли и 14 команд доступны через
  `project_instructions.find_project_instructions`, затем обычное чтение файла.
  Каталог ищется заново при запросе. Полные инструкции не копируются в адаптеры.
- Нативный инструмент `skill` отключён, чтобы OpenCode не помещал весь каталог
  в каждый запрос: первая такая проба превысила реальный контекст модели.
- Роли и команды имеют тонкие адаптеры с путями к исходным инструкциям;
  `sync_metadata.py` обновляет их при старте.
- MCP борда использует штатный `scripts/launch-task-board-mcp.sh`; секреты
  остаются в существующем локальном хранилище и не включены в профиль.
- `hooks.mjs` передаёт каноническим board hooks точные имена инструментов,
  входные аргументы и исходные результаты до compaction. Exit-zero deny
  блокирует вызов. Ошибка post-hook сохраняет квитанцию уже выполненной операции
  и требует сверки перед повтором.
- Knowledge MCP выполняет поиск по локальному индексу проекта.
- FLUX MCP возвращает текст и путь к изображению для текстовой Qwen. PNG
  сохраняются в ignored `.codex-temp/flux-images/`; генерация не публикует их.

## Проверки и границы

На изолированном кодовом примере агент прочитал файлы, внёс правку и запустил
неизменённые проверки: **15/15**, около **162 секунд** во второй попытке.
Первый вариант профиля превысил контекст модели; его неудачный результат
сохранён. Это один пример, не прогон всех тестов MeTravel.

Наличие инструмента не доказывает качество решения. Перевод реального детского
квеста RU→PL в оценке 27.11.2026 не прошёл структурную и независимую смысловую
проверку. Полный JSON нельзя автоматически считать готовым переводом.

Подходящие задачи: поиск и объяснение кода, ограниченное исправление с тестом,
черновики переводов и статей с проверкой фактов, подготовка карточек по контракту,
черновики изображений. Сложные изменения, ответы квестов и опубликованный текст
требуют независимой приёмки. Повторная проверка той же Qwen не заменяет её.

Git hooks, operation locks, независимое ревью и штатные deploy scripts сохраняются.
Конфигурация допускает обычные Git/deploy команды после выполнения правил проекта;
демонстрационный прод-деплой не выполнялся. Backend/store operations сохраняют
свои правила и authorization gates. Запрос на настройку не разрешает удаление
реальных задач, публикацию контента или экспериментальный релиз.

Разрешения клиента и инструкции **не являются общей защитной песочницей**:
разрешённые Node/Python/shell команды обладают широкими возможностями. Нельзя
давать модели неограниченное доверие к секретам и опасным операциям. Полноценный
обмен сообщениями между сессиями Claude не переносится через ACP; board claim
hooks используют свой fallback по времени при отсутствии Claude transcript.

Этот профиль текстовый: он запускает генератор картинок, но не проверяет
изображения зрением и не редактирует их. Отдельные browser/device-инструменты
в этот профиль не подключены; выполнение такой QA через shell здесь не проверялось.
Для ограниченной браузерной пробы Gemma есть отдельный
[экспериментальный QA CLI](../qa/README.md) с собственным профилем и обязательной
проверкой отчёта учителем; основной ACP этим не заменяется.
Локальный inference бесплатный; борд использует сетевое API, поэтому вся работа
не становится офлайн. Не запускать параллельно несколько тяжёлых моделей.

## Диагностика и откат

Для работы ученика под наблюдением используется отдельный небольшой профиль,
который не меняет полный режим PhpStorm:

```sh
python3 .aiassistant/universal/student.py --backend coder --kind code \
  --prompt .codex-temp/my-task/assignment.txt > .codex-temp/my-task/events.jsonl
```

`--backend current|coder|gemma` выбирает соответственно loopback **18088 / 18089 /
18091**. `current` использует штатный guard запуска Qwen; альтернативные серверы
запускает учитель последовательно. При недоступном выбранном сервере — явный
отказ без облачного или другого локального fallback. `--kind code` оставляет
борд только для чтения и поиск инструкций, отключает knowledge/FLUX и Task-каталог
ролей. `--kind cover` дополнительно включает FLUX. Файлы профилей атомарно
пишутся только в ignored `.codex-temp/local-student/`; роли остаются доступны
через поиск канонических инструкций и чтение файла.

Назначение отправляется через stdin: текст с командой тестов не появляется в
argv процесса OpenCode и не выдаётся детектору операций за запущенный тест.
Реальные команды тестов по-прежнему проходят штатные guards/locks. Обычный
`run.py` и основной профиль IDE этим ограничением не заменяются. Клиентские
запреты MCP не превращают разрешённый Bash/Node/Python в sandbox.

Лимит OpenCode `steps: 16` сам по себе — инструкция модели, а не жёсткая
остановка. Обвязка ученика отдельно останавливает 17-й шаг, третий подряд
одинаковый `glob`/`grep`/`read` с теми же аргументами (в том числе в разных
сообщениях) или попытку дольше 600 секунд. Другой инструмент или другие
аргументы сбрасывают счётчик повторов. Сырые JSON-события сохраняются; в конце
появляется `budget_stop` с причиной и счётчиками, exit code — **124**, даже если
CLI успел выйти с 0. Завершается только собственная группа процессов CLI:
TERM → ожидание до 5 секунд → KILL. Общий сервер модели не завершается.
Остановка по бюджету не считается успешно выполненной задачей.

`--session <id>` продолжает явно выбранную сессию; `--write-config-only`
подготавливает профиль без модели. Структура профиля и mock-проверки сами по
себе не подтверждают, что конкретное назначение поместилось в контекст:
фактические входные токены и результат проверяются в сыром прогоне.

Из корня проекта:

```sh
/usr/bin/python3 .aiassistant/universal/run.py mcp list
/usr/bin/python3 .aiassistant/universal/run.py debug config
/usr/bin/python3 .aiassistant/universal/sync_metadata.py --check
```

Если новый режим не появился после изменения реестра, перезапустить IDE.
Не обновлять AI Assistant до версии, несовместимой с установленным build IDE.
Исходный режим `Qwen + FLUX (local)` сохранён как отдельный ограниченный rollback;
у него нет инструментов разработки. Для отката удалить только запись
`MeTravel Local (Qwen + FLUX)` из реестра ACP, сохранив остальные записи.
