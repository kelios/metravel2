2. Собрать новое тело целиком в файл `<id>-new.html` (полный HTML, без `<html>/<body>`).

Записать: `METRAVEL_TOKEN=$(cat /private/tmp/claude-501/-Users-juliasavran-Sites-metravel2-metravel2/4064ea07-f21f-4a9b-ab53-f808a9439a3f/scratchpad/julia.token) node scripts/seo-edit.js --id <id> --desc-file <id>-new.html` — БЕЗ `--meta`.
