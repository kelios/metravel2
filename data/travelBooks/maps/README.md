# Карта мест в конце фотодневника

`countries.json` содержит исходные географические контуры Беларуси и Польши
из Natural Earth Admin 0 Countries, 1:110m, версия 5.1.1. Координаты WGS84
сохранены без изменений; из свойств оставлены код страны и русское имя.
Точная ссылка, контрольные суммы и проверка лицензии находятся в `source.json`.

Natural Earth предоставляет данные как public domain и не требует печатной
атрибуции. Источник и условия: [описание набора](https://www.naturalearthdata.com/downloads/110m-cultural-vectors/110m-admin-0-countries/),
[Terms of Use](https://www.naturalearthdata.com/about/terms-of-use/).

`render/endMap.ts` применяет одну проекцию к контуру и выбранным координатам.
Карта использует только `book.stops`: номер сохраняет порядок книги, истинная
позиция остаётся точкой, разнесённый номер связан с ней выносной линией.
Она не соединяет разные поездки в маршрут и не обращается к тайлам/API.
Нумерованная легенда формируется из существующих страниц отметок перед картой.

Цифры заданы в физических единицах: минимум 9 pt для compact и 10,5 pt для A5.
Перекрывающиеся номера раздвигаются, а не уменьшаются и не отбрасываются.
Для точной навигации читатель использует проверенный QR соответствующего места.
