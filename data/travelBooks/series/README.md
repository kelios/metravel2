# Тематические серии готовых книг

Серия — отдельный редакционный набор мест автора 1 поверх того же рендера ReadyBook (#2809).

- `catalog.json` — список серий `BookSeries{id, theme, countries, bookIds, status, title, kit, targetPlaces}`.
- `<seriesId>.json` — комплект пилота: выбранные места и резерв с причиной исключения.

Пилоты (решение владельца 01.11.2026): «Горы Польши» — 40 мест, «Замки Польши» — 30 мест, статус `planned`.

Правила, которые проверяет `node scripts/validate-ready-books.mjs --series`:

- ровно `targetPlaces` мест, без повторов внутри комплекта;
- ни одно место не совпадает и не лежит ближе 400 м к местам изданных книг BY/PL;
- для гор у каждого места есть маршрутные данные; `null` значит «ещё не проверено»;
- `ready` требует опубликованной книги из `bookIds`, проверенного разрешения фото
  и, для гор, тропы, длины, набора высоты и времени у каждого места.

Неизвестная официальная сложность, сезонность или источник хранятся явно (`unknown`/`null`)
и не подменяются догадкой.
